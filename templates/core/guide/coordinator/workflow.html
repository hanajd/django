{% if guide_coordinator_is_coordinator %}检测流程岗位{% else %}我的岗位职责{% endif %}

检测业务在系统中拆为五个流程岗位，与 App 待办、文件库资料、项目流程登记一一对应。{% if guide_coordinator_is_coordinator %}委托统筹派工前请与下表对齐预期。{% else %}请对照您账号的岗位角色（登录后侧栏下方或用户管理中的「检测岗位」）阅读对应小节。{% endif %}

一、五类岗位总览

岗位 主要工作场所 典型产出
检测员App现场检测数据、检测提交
校核员App现场记录校核签字
编制人App 为主报告编制
审核人App 为主报告审核
授权签字人App + Web 文件库报告签发；权限较全

二、检测员

  • 登录 App，在待办中进入委托统筹已分配的项目与检测项。
  • 按标准完成现场检测数据录入并提交。
  • 可在 项目工作台 查看已分配项目（只读）；在 文件库管理 → 检测提交 使用 手动导出 PDF 生成现场记录。

三、校核员

  • 在 App 中对检测员提交的内容进行校核（签字/驳回以 App 为准）。
  • 关注现场记录是否完整、读数是否合理；驳回后检测员需重新提交。
  • 可在 项目工作台 查看已分配项目（只读）；文件库核对现场记录与检测提交。

四、编制人

  • 在现场记录齐备后，在 App 完成报告编制环节。
  • 可在文件库 报告 分类查看或下载相关 PDF（若已生成）。
  • 若被指定为项目主要负责人，可能可见 项目工作台 与 委托管理。

五、审核人

  • 在 App 对报告稿进行审核；通过或退回编制人修改。
  • 数据范围较检测员更宽，文件库中可能看到项目内更多报告相关文件（仍受项目权限约束）。

六、授权签字人

  • 在 App 完成签发，为报告流程最后一环（以单位制度为准）。
  • 该岗位在 Web 上权限相对更多：可见更多文件库分类写操作，并可能进入 委托管理 查看进度。
  • 仍不能创建用户或维护医院信息——此类事项由委托统筹负责。

七、岗位衔接（委托统筹派工 checklist）

  1. 用户管理已建账号且岗位正确。
  2. 项目工作台 流程 页已登记该人。
  3. 分配 页已向检测员同步任务。
  4. 各环节人员在 App 使用本人账号，勿代登。

小结：本模块回答的是——「五个岗位各做什么、在 App 还是 Web、派工时要登记什么」。
