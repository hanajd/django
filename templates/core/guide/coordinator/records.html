现场记录与报告

委托统筹在流程后段的核心工作：督促外业在 App 完成填报，在 文件库管理 导出现场记录与报告，并按单位要求合并多份报告对外交付。下文说明业务对应关系与合并注意事项。

一、项目、设备、记录与报告

  • 一个项目下常有多台受检设备 → 往往产生多份报告。
  • 一份报告（单台设备）常汇总多份现场记录（多表、多阶段实测）。
  • 现场记录侧重过程留痕；报告是对外正式结论。二者在文件库分属 现场记录 与 报告 分类。
  • 多科室只需部分报告时，可在报告分类多选后合并，形成某一科室或对外的一套 PDF。

记忆口诀：项目管范围；现场记录管过程；报告管结论；多设备多报告；单报告常合多份现场记录；交付前常要合并报告。

二、推荐操作顺序

逐步点击说明见专篇 分工与报告导出（含人员派工与三种导出报告方式）。简版顺序如下：

  1. 项目工作台 · 人员派工 完成分工，检测员在 App 提交。
  2. 检测提交 → 勾选 → 手动导出 PDF（现场记录）。
  3. 校核员等在 App 完成校核（若流程要求）。
  4. 检测提交 / 现场记录 → 导出合并报告 或 手动导出报告 → 写入 报告。
  5. 编制、审核、签发岗位在 App 完成各自环节。
  6. 多台设备合订：报告 分类勾选 ≥2 份单台报告 → 报告合并。

三、合并报告注意事项

  • 合并输入应为每台设备各一份、尚未合并过的单台报告 PDF；勿把已合并的大文件再次合并。
  • 合并稿会自动生成目录页，章节名来自各 PDF 内「三、检测结果」中的设备信息；合并后请检查目录设备名、1.1 / 2.1 等小节与页码是否合理。
  • 若某章显示「检测设备」或目录混入表读数（如 kV、mm），多为该份 PDF 文本层不规范；应回到单台报告源文件修正后重新导出再合并。
  • 在 医院信息管理 维护好设备名称与型号，有助于目录识别正确。

四、导出失败常见原因

  • 项目未挂对应检测任务或未在 App 提交数据。
  • 未勾选文件或勾选了不可导出的分类。
  • 流程岗位未登记，导致编制/审核环节未走完（以单位流程为准）。

小结：本模块回答的是——「何时导出记录与报告、多份如何合并交付、合并后如何验目录」。
