# 8 工作场所布局

| 元数据 | 值 |
|--------|-----|
| id | `workplace_layout` |
| 类型 | 按区位组稿 + 表4/表5（手工）+ 附图占位 |
| 标准 | GBZ 130-2020 §6.1 |
| 组稿 | `templates/common/workplace_layout/` |

## 应描述内容

1. 机房门、控制室门配备情况  
2. 射线束照射情况  
3. 机房有效使用面积和最小单边长度（见表4）  
4. 毗邻情况（见表5）  
5. 选址合理性分析  

## 正文结构（按信息表场所区位分组）

```
1.{区位}{机房简称…}
如图{n}所示，建设单位拟在{区位}设置{台数表述}，拟各自设置单独的机房，并设置共用的控制室，且拟与机房分开设置。
…防护门 / 控制室门 / 观察窗…
…有用线束朝向…
…最小有效使用面积和最小单边长度见表4、毗邻情况见表5。
…选址位置已充分考虑邻室（含楼上和楼下）…
【此处插入平面布局图】
图 n  {区位}平面布局示意图

综上所述，…符合GBZ 130-2020…
```

平面布局图实际挂在栏目**末尾**（A3 横置整页图），正文仅保留「如图n所示」引用；不再在段中插入占位。

## 表4 / 表5

| 表 | 内容 | 维护方式 |
|----|------|----------|
| 表4 | 机房有效使用面积和最小单边长度 | **手工填设计值**；标准列由 `room_size_limits.json` 预填 |
| 表5 | 机房毗邻情况 | **手工填**东/西/南/北/楼上下 |

## 附图（栏目末尾）

- 从评价信息表 PDF **按页序**识别「平面布局」页（排除通道走向、地理位置等）  
- **整页渲染**为图片（不拆组件）  
- 以 `extra_figures::workplace_layout` 挂在工作场所布局栏目之后，**每页一张 A3 横置**  
- 图例/放射分区叠加、通道走向图暂不自动生成  

生成器：`f1_eval_report.templates.workplace_layout.assemble_workplace_layout`  
附图提取：`extract_workplace_layout_figures`
