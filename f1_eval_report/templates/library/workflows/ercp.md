# 图　ERCP（手术）工作流程

```
患者情况调查、登记 → 放射诊断可能受到的辐射危害告知
        ↓
正当性判断
   ├─ 未通过 → 不进行医用 X 射线影像诊断实践
   └─ 通过 → 预约登记 → 患者候诊
        ↓
实施医用 X 射线诊断前准备 → 受检者进入机房、摆位（机房内）
        ↓
无关人员退出机房
        ↓
工作人员隔室操作：患者被曝光（产生 X 射线）→ 确认图像质量符合
        ↓
注射造影剂
   ├─ 患者被曝光（隔室，产生 X 射线）→ 操作完毕患者离开
   └─ 机房内操作 ERCP 进行胰胆管造影程序（产生 X 射线）→ 操作完毕患者离开
```
