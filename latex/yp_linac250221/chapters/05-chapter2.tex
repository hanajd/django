\section{分析}

\subsection{医用电子直线加速器工程分析}

\subsubsection{医用电子直线加速器工作原理}

医用电子直线加速器可利用电子束或 X 射线束对患者病灶进行照射。典型结构单元包括：加速管、电子枪、微波系统、调制器、束流传输及准直系统、真空系统、恒温水冷系统和控制保护系统等。电子在加速管中获得能量后，可作为电子线输出，或打靶产生 X 射线输出。建设项目拟涉及的加速器通常具备 VMAT、IMRT、IGRT 等功能，可配备 CBCT、EPID，并具有常规模式与非均整（FFF）模式。

（请补充本项目拟购加速器原理框图、内部结构示意及功能配置说明。）

\subsubsection{医用电子直线加速器放射治疗流程}

\begin{enumerate}
\item 患者经诊断与治疗正当性判断后预约放疗；
\item 体位固定与 CT 模拟定位，影像传至治疗计划系统；
\item 医师勾画靶区与危及器官，物理师制定并优化计划；
\item 计划验证与确认后实施治疗；
\item 治疗中按规程摆位、出束、记录；治疗结束后患者离开，设备回零。
\end{enumerate}

\subsection{CT模拟定位工程分析}

\subsubsection{CT模拟定位工作原理}

CT 模拟定位机通过 X 射线断层成像获取患者定位影像，用于放疗靶区勾画与计划设计。主要参数包括管电压、管电流、孔径等。

\subsubsection{CT模拟定位工作程序}

\begin{enumerate}
\item 患者体位固定与标记；
\item CT 扫描获取定位影像；
\item 影像传输至治疗计划系统；
\item 医师/物理师据此制定放疗计划。
\end{enumerate}
