# 4 建设项目分类

| 元数据 | 值 |
|--------|-----|
| id | `project_classification` |
| 类型 | 判定生成 |
| 依据 | 装置清单 + 2017 年第 66 号公告 |

## 判定步骤

1. 读取评价信息表射线装置清单  
2. 对照《关于发布〈射线装置分类〉的公告》（环境保护部、国家卫生和计划生育委员会 2017 年第 66 号公告）确定每台/类装置类别  
3. 按《放射诊疗建设项目卫生审查管理规定》判定危害严重 / 危害一般  

## 输出模板

```
本项目涉及的射线装置（{装置简述}）属于{射线装置类别}；本项目属于放射性危害程度与诊疗风险{危害类别}类放射诊疗建设项目。
```
