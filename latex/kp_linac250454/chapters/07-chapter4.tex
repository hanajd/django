\subsection{工作场所分区}

为便于放射防护管理和职业照射控制，建设单位拟按照放射工作场所分区管理原则，将本项目相关放射工作场所划分为控制区和监督区，放射分区图见图~\ref{fig:ch4-zoning}，具体分区方案见表~\ref{tab:ch4-zoning}。

根据标准GBZ/T201.2-2011，本报告将医用电子直线加速器、CT模拟定位机使用的治疗源视为点状裸源，4π立体角发射各向同性初级γ辐射，故医用电子直线加速器、CT模拟定位机房的墙体和顶棚应考虑初级辐射，机房入口应考虑散射辐射。由于医用电子直线加速器、CT模拟定位机的使用位置不是固定的，在医用电子直线加速器、CT模拟定位机房内一定范围内使用，本报告保守估计，使用范围为距离各墙体内壁 $1 . 0 \mathrm { m }$处的矩形区域内（见图~\ref{fig:ch4-points-plan} 中 o1-o2-o3-o4 包裹区域），辐射源距机房地面高 $1 . 0 \mathrm { m }$。综合考虑安全和人员可到达等因素，提出建设项目医用电子直线加速器、CT模拟定位机房选取相应关注点进行评价，关注点见表~\ref{tab:ch4-points} 所示。

\subsubsection{辐射屏蔽验证计算公式}

本评价报告采用《放射治疗机房的辐射屏蔽规范第1 部分：一般原则》（GBZ/T201.1-2007）和《放射治疗机房的辐射屏蔽规范第 3 部分：电子直线加速器放射治疗机房》（GBZ/T 201.2-2011）中的公式对医用电子直线加速器、CT模拟定位机房屏蔽厚度进行计算，具体如下。

一、医用电子直线加速器、CT模拟定位机房墙体屏蔽计算
\begin{equation}
    \dot{H_0}=A\cdot K_r
\end{equation}
\begin{equation}
    X=\left[TVL\cdot \log\left(\dfrac{\dot{H_c}}{\dot{H_0}}\cdot \dfrac{R^2}{f}\right)^{-1}+(TVL_1-TVL)\right]\cos\theta
\end{equation}
\begin{equation}
    \dot{H}=\dfrac{\dot{H_0}\cdot f}{R^2}\cdot 10^{-(X\cdot \sec\theta+TVL-TVL_1)/TVL}
\end{equation}

式中：

$\dot { H } _ {0}$— 放射源在距其1m处的剂量率， $\mu \mathrm { S v / h }$；

$A$—为$\gamma$放射源 X射线活度，MBq；

$K _ { r }$—为比释动能率常数，单位（ $\mu \mathrm { G y } . \mathrm { m } ^ { 2 }$）/(h·MBq)；

$\dot { H } _ { c }$—参考点剂量率参考控制水平， $\mu \mathrm { S v / h }$；

$R$—辐射源点（靶点）至关注点的距离， $\mathbf { m }$；

$f$—对有用束为1；

$TVL$—辐射在屏蔽物质中的平衡什值层厚度，mm；

$TVL_1$—辐射在屏蔽物质中的第一个什值层厚度，mm；此处 $T V L _ {1}  = T V L$

$\theta$—斜射角，即入射线与屏蔽物质平面的垂直线之间的夹角。

$X$—所需屏蔽物质厚度，单位：mm；

$X _ { 1 }$—建设单位设计屏蔽物质厚度，单位： $\mathrm { m m }$；

$\dot { H }$—距离辐射源R处的剂量率， $\mu \mathrm { S v / h }$；

\subsection{放射性“三废”处理措施}

\subsubsection{放射性固体废物}

本项目不涉及放射性固体废物的产生，无需进行放射性固体废物治理，本项目更换废旧放射源均由供应商回收处理。

\subsubsection{放射性废气}

本项目不涉及放射性废气的产生，无需进行放射性废气治理。

\subsubsection{放射性废水}

本项目不涉及放射性废水的产生，无需考虑放射性废水影响。
