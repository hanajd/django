# 检测仪器台账：出库 / 入库与派工占用

## 1. 业务规则

| 概念 | 说明 |
|------|------|
| 物理仪器 | 台账中 **一行** = 一台仪器，**编号 `code` 全局唯一** |
| 同种仪器 | **名称 + 型号** 相同的多条台账（多台设备），编号不同 |
| 在库 | 未关联任何进行中的项目（以 `checkout_project_ids` 为准，不仅看 `checkout_project`） |
| 已出库 | 可关联 **多个** `LibraryProject`（`checkout_project_ids`）；多台设备/多委托可共用 |
| 任务模板绑定（推荐） | `bindingMode=kinds`，仅存 **种类**（`name`+`model`），不存具体编号 |
| 任务模板绑定（兼容旧版） | `bindingMode=ids` 或列表 `[qc_id, rp_id]` / 对象内 id 数组，仍可读可派工 |
| 项目派工分配 | `LibraryProject.assigned_instrument_ids` 含 `shareMode`、`byTask`（按任务模板）及汇总 id 列表 |
| 跨模板策略 | `instrument_share_across_tasks=False`（默认）：各现场记录模板分别选一台；`True`：同种整项目共用一台。同模板下多台设备始终共用 |
| 出库顺序 | 默认同种在库按台账 **`code` 升序** 依次占用（`JL-001` → `JL-002` …） |

示例：委托含 2 台设备共用模板 A、1 台设备用模板 B，均需要同种剂量仪。默认分配 2 台（A 一台、B 一台）；若勾选「跨模板共用」则只分配 1 台。

## 2. 数据模型

- `InstrumentCatalog.checkout_project_ids`：出库关联的项目 id 列表（多项目共用）  
- `InstrumentCatalog.checkout_project` / `checked_out_at` / `checked_out_by`：最近出库展示与审计  
- `InstrumentCheckoutLog`：出库、入库流水（审计）

迁移：`apps/core/migrations/0050_instrument_checkout_inventory.py`

## 3. 派工联动

**项目工作台 → 人员派工 → 向检测人员同步 App 任务** 时：

1. **种类模式**：汇总模板要求的仪器种类（质控/防护各若干槽位）；  
2. **旧版 id 模式**：读取模板绑定的 id 列表（兼容 `[qc, rp]`、对象内数组）；  
3. **同步 App 任务时**按台账 **编号顺序** 从在库挑选具体设备，写入 `assigned_instrument_ids` 并出库；旧版若模板指定编号已被其他项目占用，则 **同种顺延下一编号**；  
4. 同种在库台数不足时暂**不阻止同步**（软模式，仅提示）；  
5. 已分配编号展示在派工页；**保存手动分配或自动重分配时**会调用 `sync_project_instrument_checkout`：从分配中移除的仪器 **自动对本项目入库**（仅解除本项目关联，其他委托仍可共用），新增的 **自动出库**。
6. 委托结束停用项目时，本项目关联仪器全部入库。

派工页展示「检测仪器出库状态」表（只读）；**不再提供单独的手动出库/入库按钮**（随分配保存自动同步）。

### 自动出库 / 入库（2025-05 起）

| 时机 | 行为 |
|------|------|
| 保存手动分配仪器 | 与当前分配列表 **双向同步**：取消勾选的仪器对本项目 **入库**，新勾选的 **出库** |
| 项目进入检测环节 | 委托设备加入项目后、或 **人员派工 → 确认同步 App 任务** 时，按模板种类与台账编号顺序 **自动出库**（并入库已不在列表中的旧绑定） |
| 委托结束 | **停用项目**（文件库/项目管理）或删除项目前，本项目仪器 **自动全部入库** |

## 4. 台账管理

**数据库管理 → 检测仪器**：维护资料（编号、证书等）与查看在库/出库状态。正常出库/入库随项目派工与委托结束自动同步；也可在台账对仪器点 **出库**，选择委托项目、受检设备与现场记录检测项后手动登记（与项目工作台仪器管理一致）。若台账仍显示「已出库」而仪器已实际归还，可对已出库行点 **落库** 手动恢复在库。

## 5. 登记 API

`GET …/registry/instruments/` 响应增加（只读）：

| 字段 | 说明 |
|------|------|
| `inventoryStatus` | `in_stock` / `checked_out` |
| `checkoutProjectId` | 当前出库项目 id，可空 |
| `checkoutProjectCode` | 项目编码，可空 |
