# 组织主任 / 主管账号说明

> 用于联调与演示。由 `python manage.py ensure_org_directors` 幂等创建/更新。  
> **请在正式环境尽快修改密码。**

## 账号一览

| 部门 | 角色 | 用户名 | 初始密码 | 组织部门 `org_unit` |
|------|------|--------|----------|---------------------|
| 行政部 | 行政 | `admin_director` | `Director@2026` | `admin_office` |
| 检测部 | 检测部主管 | `inspection_director` | `Director@2026` | `inspection` |
| 评价部 | 评价部主管 | `evaluation_director` | `Director@2026` | `evaluation` |

## 能力摘要

| 账号 | 医院信息 | 建项 | 项目工作台 / 派工 | 本部门用户管理 | 任务模板库 |
|------|----------|------|------------------|----------------|------------|
| `admin_director` | 可写 | 可 | 可见（不管流程细节） | 无 | 无 |
| `inspection_director` | 不可写 | 否 | 可派本部门员工 | 有（侧栏最下方） | 无 |
| `evaluation_director` | 不可写 | 否 | 可派本部门员工（评价预留） | 有（侧栏最下方） | 无 |

检测部 / 评价部主管的「用户管理」入口固定在侧栏**最下方**（业务菜单之下），便于管理本部门员工账号与邀请链接。

## 重建命令

```bash
python manage.py ensure_org_roles
python manage.py ensure_org_directors
# 自定义密码：
python manage.py ensure_org_directors --password 'YourStrongPass'
```

## 相关角色 code

- `admin_office` — 行政  
- `dept_director_inspection` / `dept_staff_inspection` — 检测部主管 / 员工  
- `dept_director_evaluation` / `dept_staff_evaluation` — 评价部主管 / 员工  

与旧轨「委托统筹」`commission_coordinator` 并行，互不替代。
