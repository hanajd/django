# 9 防护设施和措施

| 元数据 | 值 |

## （1）放射防护分区

### 文字（固定格式）

```
本项目{room_count}间X射线设备机房工作场所放射防护分级设计情况及评价见表6，本项目控制区和监督区划分明确且合理，符合标准的相关要求。
表6 本项目放射防护分级设计情况及评价
```

`{room_count}` 来自信息表射线装置清单（按机房位置去重，如 16）。

表6 默认**汇总一行**：
`{room_count}间X射线设备机房内部区域（见图…）` / 监督区同理。

「见图…」规则：只统计**表6之前**已上传的附图，题注匹配「平面布局 / 放射分区」（排除通道、通风、总平面）；图号接在危害因素分析流程图之后顺延。

常用模板：**防护设施和措施**
- 导语：`zoning_intro.md`（可改句式，保留 `{room_count}`）
- 表6：`table6.json`（可继续手工改见图号等）

提取信息表时会按装置清单重算导语与表6。

### 划分原则（固定）

- **控制区**：X 射线机房内部  
- **监督区**：与控制区相邻且人员可达的区域  

### 表格（表6）

| 列 | 规则 |
|----|------|
| 设计情况（控制区 / 监督区） | 按机房预填，可在表内编辑 |
| 标准要求 | 预填后在表内编辑（无单独「标准要求」模板） |
| 评价 | 默认「符合」，可改 |

## （2）屏蔽设施

### 文字结构

导语 → **表7** → 表后总结 / 建议 / 要求（用 `<<<F1_TABLE>>>` 插入表位）。

```
建设单位根据拟配备的射线装置类型、参数对本项目所在共计{room_count}间X射线设备机房屏蔽设施进行设计，其设计情况见表7所示，各机房屏蔽体的设计厚度均不低于GBZ 130-2020《放射诊断放射防护要求》的相关要求。

表7 本项目X射线设备机房屏蔽设计情况及评价

综上所述，本项目{room_count}间X射线设备机房拟采取的各屏蔽体等效铅当量均不小于GBZ 130-2020《放射诊断放射防护要求》要求的屏蔽铅当量厚度，但部分屏蔽体设计偏保守。
建议：…可适当减少…部分屏蔽体屏蔽材料厚度。
要求：砂浆饱满、推拉门缝隙、防护地槽、门墙搭接、管线穿墙口等（固定长文）。
```

常用模板：
- 导语：`shielding_intro.md`（保留 `{room_count}`）
- 表7：`table7.json`（可编辑；对照信息表屏蔽设计情况表填写）
- 表7标准要求：`shielding_standards.json`（GBZ130 铅当量，按设备类型预填表7「标准要求」列）
- 表后：`shielding_after.md`（保留 `{room_count}`）

提取信息表时按装置清单重算导语、表7骨架与表后。

### 表格（表7）

| 列 | 说明 |
|----|------|
| 屏蔽体 | 四周墙体、观察窗、防护门、顶板、地板等 |
| 屏蔽设计 | 材料及厚度 / 总等效铅当量（mmPb），由信息表组稿 |
| 标准要求 | 按机房设备类型从 `shielding_standards.json`（GBZ130）预填，可在常用模板中维护 |
| 评价 | 对照铅当量与标准，默认「符合」 |

**合并规则**：仅当**同一位置**下，墙体/顶板/地板/门窗等屏蔽字段完全一致且设备类型相同的机房才合并，如「九、医技楼二楼介入中心DSA机房1和DSA机房2」。不同楼栋/楼层（如门急诊楼与发热门诊）即使屏蔽相同也不合并。

**上标/下标**：单元格支持 pandoc 标记 `^①^`（上标）、`~2~`（下标）；表头「屏蔽设计^①^」「(mmPb)^②^」及表注中的密度单位 `cm^3^` 会按上标绘制。表格编辑器工具栏提供「X² / X₂」按钮。

常用模板：

## （4）个人防护用品

导语 → **表9（配置要求）** → **表10（配备计划）** → 表后总结（正文用两个 `<<<F1_TABLE>>>`）。

```
根据建设单位提供的信息，{eval_basis}本项目{room_count}间X射线设备机房放射防护用品配备计划如表10所示，根据表9的配置要求，符合GBZ 130-2020《放射诊断放射防护要求》的要求。

表9 个人防护用品和辅助设施配置要求
表10 本项目个人防护用品和辅助设施配置计划

综上所述，本项目{room_count}间X射线设备机房个人防护用品配备计划符合GBZ 130-2020《放射诊断放射防护要求》的要求。
```

常用模板：
- 导语：`ppe_intro.md`（`{room_count}`、`{eval_basis}`）
- 表9：`table9.json`（GBZ 130-2020 表4，固定）
