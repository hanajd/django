# 3 项目概述

| 元数据 | 值 |
|--------|-----|
| id | `project_summary` |
| 类型 | 表单填入 + 机房明细补全 + 固定总结 |
| 数据来源 | 评价信息表（单位简介/项目简介/委托日期/评价单位）；建设地址；《放射防护设施屏蔽设计情况表》位置与机房名称 |

## 内容块

| 块 | 来源 | 类型 |
|----|------|------|
| 单位简介 | 评价信息表「单位简介」 | 表单 |
| 项目简介（完善） | 信息表「项目简介」+ 建设地址 + 屏蔽表机房明细 + 委托日期/评价单位 | 表单+生成 |
| 总结性文字 | 固定句式 | 固定 |

## 组装顺序

```
{单位简介}

{完善后的项目简介}
  ——动机句 + 建设地址 +「拟在……建设以下……项目：」
  ——（1）（2）… 机房明细（来自屏蔽设计情况表）
  ——新购说明 + 法规引用 + 委托日期/评价单位/本项目简称

{总结性文字}
```

## 总结性文字（固定）

```
评价单位接受委托后，在认真分析论证建设单位提供的本项目相关文件的基础上，结合调查情况，根据国家相关法律、法规、标准、规范编制了本项目放射性职业病危害预评价报告表。
```

> 建设项目分类结论写入「建设项目分类」栏目，不再放在项目概述末尾。
