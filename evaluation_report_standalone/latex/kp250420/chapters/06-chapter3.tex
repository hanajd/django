\section{不同运行状态下的辐射源项}

\subsection{正常运行状态下的辐射源项}

本项目后装治疗机正常运行状态下的辐射源项为含密封源装置（后装治疗机），其产生的辐射种类有如下：

（1）初始辐射

$^ { 1 9 2 } \mathrm { I r }$源发射的γ初始辐射（平均能量0.370MeV）。治疗状态下， $^ { 1 9 2 } \mathrm { I r }$驻留施源器中，按裸源考虑，机房内空气比释动能率较高。

（2）泄漏辐射和散射射线

泄漏辐射是后装治疗机在正常运行或 $^ { 1 9 2 } \mathrm { I r }$放射源贮存状态下，穿过屏蔽壳体发射出的射线，具有较强的穿透能力。后装机正常运行时，在非治疗状态下， $^ { 1 9 2 } \mathrm { I r }$封装在后装机的贮源器内，的贮源器最大装载活度时，贮源器表面 5cm 处泄漏辐射所致周围剂量当量率不大于 $5 0 \mu \mathrm { S v / h }$；贮源器表面 $1 0 0 \mathrm { c m }$处泄漏辐射所致周围剂量当量率不大于 $5 \mu \mathrm { S v / h }$。散射辐射是 $^ { 1 9 2 } \mathrm { I r }$放射源衰变产生的有用射线束照射到物体上产生的次级射线，散射辐射可分为一次、二次和多次散射辐射，散射辐射能量比有用辐射和泄漏辐射低，穿透能力较弱

\subsection{异常或事故状态下的辐射源项}

异常运行或事故状态下的含密封源装置（后装治疗机）会产生$\gamma$射线，主要产生的原因有：

\begin{enumerate}
\item 后装治疗机设备故障（如到达预置治疗时间，放射源无法自动收回、卡源或遗落在患者体内、紧急停机按钮失灵、安全联锁装置失灵等故障）引起人员误照射或使放射治疗患者实际照射剂量偏离处方剂量 $2 5 \%$以上；
\item 工作人员或检修人员未按程序操作而造成的人员误照射；
\item 人员误入或滞留后装治疗机房造成的人员误照射；
\item 后装治疗机房屏蔽设施损坏造成机房外人员的额外照射；
\item 换装放射源后的废源因管理不善发生被盗、丢失等事故，可能造成对公众的意外照射。
\end{enumerate}

\section{小结}

由上述分析可见，本项目拟涉及含密封源装置（1台后装治疗机，使用1枚放射源 $^ { 1 9 2 } \mathrm { I r }$）的使用、非放射性职业病危害因素（臭氧、氮氧化物）。
