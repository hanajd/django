检测仪器台账

入口：左侧 检测仪器台账。本页登记每台检测仪器的编号、名称型号、证书，并查看在库 / 已出库状态。仪器编号与项目派工、现场检测记录关联，请保持资料准确、及时纠正异常占用。

一、台账里有什么

  • 一行一台仪器：编号 code 全局唯一；名称 + 型号相同的多条记录表示「同种多台设备」。
  • 在库：未关联任何进行中的项目出库记录，可供新项目分配。
  • 已出库：已登记至一个或多个检测项目（列表「出库项目」列展示最近关联项目）。
  • 页顶统计卡片可快速查看在库 / 已出库数量；支持按编号、证书检索及按状态筛选。

二、与项目工作台的关系

任务模板通常绑定仪器种类（名称 + 型号），不绑具体编号。具体编号在项目中分配：

  1. 项目工作台 → 选中项目 → 仪器管理：查看本项目所需种类、手动调整分配（若业务需要）。
  2. 项目工作台 → 人员派工：同步 App 任务时，系统按种类从在库仪器中按编号顺序自动挑选并出库。
  3. 分配结果写入项目的仪器分配记录，同时更新本台账的出库状态。

完整派工与导出流程见 分工与报告导出；项目各标签说明见 项目工作台。

三、自动出库 / 入库（正常情况）

  • 出库：项目派工保存、手动分配仪器、或进入检测环节自动分配时，对应编号登记为「已出库」。
  • 入库：在项目 仪器管理 中取消该仪器绑定并保存，或委托结束（项目停用）时，系统自动解除本项目关联；仅当所有项目都不再占用时才恢复「在库」。
  • 同种多台仪器按台账编号升序依次占用（如 JL-001 → JL-002）。

四、维护资料（新增 / 编辑）

具备维护权限的账号可点 新增仪器 或行内 编辑资料，填写编号、设备名称、型号、检定单位、证书编号与有效期等。编辑资料不会改变出库状态。

五、台账手动出库

行内点 出库，按顺序选择：

  1. 委托项目：进行中的检测项目。
  2. 受检设备：该项目委托立项已挂载的设备（与医院信息、任务模板一致）。
  3. 检测（现场记录）：该设备下需使用仪器的现场记录环节；选项来自医院信息挂载的报告/现场记录任务链。
  4. 若模板同时要求质控与防护仪器，还需选择仪器用途（质控或防护）。

确认后将仪器写入该项目对应检测项的分配记录，并登记出库；与 项目工作台 · 仪器管理 手动分配效果一致。

六、手动落库（异常纠正）

若出现项目侧仪器已归还或分配已取消，但台账仍显示「已出库」，会导致后续项目无法出库该编号。此时可在本页对已出库行点 落库：

  • 将仪器恢复为在库，解除与全部关联项目的出库记录。
  • 同步从各项目的仪器分配列表中移除该编号（避免项目仍绑定已入库仪器）。
  • 操作前会弹出确认；编辑弹窗内对已出库仪器也可点 落库。

注意：落库是纠正台账与实际情况不一致的手段，不能代替正常的项目内仪器分配流程。仪器仍在现场使用时请勿落库。

七、常见问题

  • 出库弹窗无设备/检测项：确认项目已在工作台完成委托立项；仪器种类须与任务模板要求一致。
  • 派工提示同种在库不足：筛选「仅已出库」查看占用情况；确认前序项目是否已结束或应对占用仪器落库。
  • 看不到新增 / 落库按钮：需业务登记、派工或管理员等维护权限；只读账号仅可查看。
  • 多台设备共用一台仪器：系统支持一机多项目共用；落库会一次性解除全部项目关联，请确认无项目仍在使用该编号。

小结：台账回答的是——「每台仪器的资料与在库状态」；项目内分配与自动出库在 项目工作台 · 仪器管理 / 人员派工 完成，异常占用在本页 落库 纠正。
