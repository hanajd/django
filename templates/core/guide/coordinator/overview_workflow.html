整体工作顺序

您的账号由委托统筹创建，岗位为检测流程中的一环（检测员、校核员、编制人、审核人或授权签字人）。多数现场工作在 平板 App 完成；Web 后台主要用于查看、上传或下载与岗位相关的资料。请先确认委托统筹已在 项目工作台 把您加入项目并同步了任务。

一、您通常能看到哪些菜单

  • 文件库管理：按岗位不同，侧重 现场记录、报告、检测提交 等（无模板维护、无文档识别）。
  • 项目工作台：凡已被派工登记者均可进入，仅查看分配给您的项目。检测员、校核员为只读（可看进度）；编制人、审核人、授权签字人可编辑委托立项 / 派工 / 仪器管理等。
  • 委托管理：若您被分配了项目任务或登记为流程成员，可查看与自己相关的委托进度。
  • 无 用户管理、医院信息管理、任务模板库、模板编辑器。

二、典型一天怎么配合系统

  1. 用本人账号登录 App，在待办列表进入委托统筹已分配的检测项目。
  2. 按岗位在 App 内完成填报、校核、编制、审核或签发（具体以 App 界面与单位制度为准）。
  3. 提交后，数据会进入 Web 文件库管理 的 检测提交 或生成 现场记录 / 报告 类文件。
  4. 若需在 Web 补传附件或下载 PDF，进入文件库对应分类操作；一般只能删除本人上传的文件。

三、遇到问题找谁

  • App 看不到项目或任务：联系委托统筹，确认是否已派工、是否选对账号登录。
  • 需要改医院/设备信息、增删账号：由委托统筹在对应菜单处理，您无权限操作。
  • 报告导出与合并：编制人、审核人、授权签字人可在文件库操作；检测员、校核员仅可在 检测提交 使用 手动导出 PDF（现场记录）。

小结：流程岗位账号回答的是——「接到派工后，在 App 与文件库中完成本岗位环节」；详细分工见下一篇「我的岗位职责」。
