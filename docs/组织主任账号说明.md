# 组织主任账号说明

> 用于联调与演示。由 `python manage.py ensure_org_directors` 幂等创建/更新。  
> **请在正式环境尽快修改密码。**

## 账号一览

| 部门 | 角色 | 用户名 | 初始密码 | 组织部门 `org_unit` |
|------|------|--------|----------|---------------------|
| 行政部 | 行政 | `admin_director` | `Director@2026` | `admin_office` |
| 检测部 | 检测部主任 | `inspection_director` | `Director@2026` | `inspection` |
| 评价部 | 评价部主任 | `evaluation_director` | `Director@2026` | `evaluation` |

## 能力摘要

| 账号 | 医院信息 | 建项 | 委托管理 / 项目工作台 | 本部门用户管理 | 评价报告表 | 评价报告书 |
|------|----------|------|------------------------|----------------|------------|------------|
| `admin_director` | 可写 | 可 | 可见（不管流程细节） | 无 | 无 | 视角色权限 |
| `inspection_director` | **只读** | 否 | 检测委托（派工/仪器/进度等，功能不变） | 有（侧栏最下方） | 无 | 通常无 |
| `evaluation_director` | **只读** | 否 | **评价看板**：评价报告表 + 评价报告书 | 有（侧栏最下方） | 有：新建/删除/指派项目 | 有（`perm_evaluation_report`） |

评价部角色：关闭 `perm_assign_tasks` / `perm_biz_registry`；侧栏不展示仪器台账与检测报告链路。  
评价部两页分工：**委托管理** = 派工/完成进度总览；**项目工作台** = 精简列表，一键打开/新建评价报告表。  
**评价报告书**（LaTeX PDF）与 **评价报告表**（F.1）是两条产品线，说明见 [评价报告书-LaTeX功能说明.md](评价报告书-LaTeX功能说明.md)。

检测部 / 评价部主任的「用户管理」入口固定在侧栏**最下方**（业务菜单之下），便于管理本部门员工账号与邀请链接。

## 重建命令

```bash
python manage.py ensure_org_roles
python manage.py ensure_org_directors
# 自定义密码：
python manage.py ensure_org_directors --password 'YourStrongPass'
```

## 相关角色 code

- `admin_office` — 行政  
- `dept_director_inspection` / `dept_staff_inspection` — 检测部主任 / 员工  
- `dept_director_evaluation` / `dept_staff_evaluation` — 评价部主任 / 员工
