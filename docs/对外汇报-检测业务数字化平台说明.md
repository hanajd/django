# 第一部分：开篇与背景

## 建议页 1｜封面

**标题**：放射检测业务数字化平台  
**副标题**：后台管理 + 移动检测 + 智能报告 + 评价报告自动生成  
**页内要点**：
- 委托立项 → 现场检测 → 质控审核 → 报告签发 → 归档交付
- Web 后台 + 平板 App 协同
- 支持多设备、多科室、多报告合并交付
- **评价报告**：按类别上传素材 → 规则提取 → LaTeX 国标排版 → 一键成稿（规划中）

**讲稿提示**：本平台服务于医疗机构放射设备质量控制检测、工作场所放射防护检测等业务，将原先分散在纸质表格、Excel、人工排版中的流程，统一到一套可配置、可追溯的数字化体系中。

## 建议页 2｜建设背景与行业痛点

**页内要点**：

| 传统模式痛点 | 数字化平台应对 |
|-------------|---------------|
| 检测表格版式多、更新慢 | 模板库集中维护，版式一次配置、全项目复用 |
| 现场手写/拍照，回所再录入 | App 现场填报，数据实时结构化入库 |
| 多人并行检测，进度难掌握 | 项目工作台统一派工，提交状态一目了然 |
| 报告编制靠人工复制粘贴 | 现场数据自动回填报告 PDF，减少差错 |
| 质控审核、授权签字流程长 | 五岗流程线上推进，支持跨项目集中审核/签发 |
| 多设备多科室交付材料繁杂 | 报告合并功能，一键生成总报告对外交付 |
| 「评价」章节靠人工撰写、排版费时 | **评价报告自动生成**：多格式素材上传 → 规则提取 → LaTeX 国标渲染（规划中） |
| 历史资料检索困难 | 文件库分类归档，按项目/设备/委托单位追溯 |

**讲稿提示**：强调不是单纯「电子化填表」，而是 **项目组织 + 流程管控 + 自动成稿 + 合规留痕** 的闭环。

## 建议页 3｜平台定位（一句话 + 三角模型）

**核心定位**：

> 在后台定好「项目—任务—版式—人员」，在 App 上完成现场填报与签字，在后台与文件库中形成可追溯的现场记录与正式报告。

**三角协同模型**：

```text
        ┌─────────────┐
        │  Web 后台   │  配置中心：立项、模板、派工、审核、归档
        └──────┬──────┘
               │
    ┌──────────┼──────────┐
    │          │          │
    ▼          ▼          ▼
┌────────┐ ┌────────┐ ┌────────┐
│平板 App│ │ 文件库 │ │仪器台账│
│现场作业│ │成果归档│ │资源管理│
└────────┘ └────────┘ └────────┘
```

**页内要点**：
- **后台**：管理与配置中枢，面向管理员、项目负责人、质控人员
- **App**：现场作业终端，面向检测员及流程各环节签字人
- **文件库**：全部成果的「数字档案室」，支持预览、下载、合并

## 建议页 4｜建设目标与预期效益

**页内要点**：

| 目标维度 | 具体效益 |
|---------|---------|
| **效率** | 减少重复录入与手工排版，提交即生成现场记录/报告 PDF |
| **质量** | 判定标准自动比对、单项判定规则统一，降低人为疏漏 |
| **协同** | 多名检测员并行作业，审核/签字人可跨项目集中处理 |
| **合规** | 五岗流程留痕、签名归档、全链路可追溯 |
| **扩展** | 新设备类型、新版式通过模板库配置，无需改程序 |
| **交付** | 多份报告合并为一份总报告，满足医院多科室统一交付 |
| **成稿** | 评价章节由素材自动汇总生成，LaTeX 国标排版，减少人工撰写（规划中） |

**讲稿提示**：可结合本单位数据补充「单份报告编制时间缩短 X%」「返工率下降」等实例（若有）。

## 建议页 8｜医院信息与委托立项

**业务流程**：

```text
登记委托单位（医院 → 院区 → 科室）
    ↓
登记科室设备（设备类型、型号、绑定报告模板）
    ↓
创建检测项目（生成委托编号）
    ↓
委托立项：勾选本次要检测的设备 + 检测类型
    ↓
系统自动挂载对应任务模板，进入派工环节
```

**页内要点**：
- 支持 **11 类设备类型**（CT、DR、DSA、口腔 CBCT、口片机等）与 **验收/状态/防护** 等检测类型组合
- 同一设备可配置多种检测类型（如验收 + 状态），立项时选择本次执行哪一种
- 设备检测历史可查询，便于年度复测与台账管理
- 支持将 **合并报告** 绑定到医院/院区/科室节点，方便对外统一交付

**讲稿提示**：医院信息树一次维护、多次复用，避免每个项目重复录入单位与设备信息。

## 建议页 9｜项目工作台（核心中枢）

**六大页签**：

| 页签 | 功能 |
|------|------|
| **概览** | 任务数、分配人数、提交数、流程状态一览 |
| **任务与模板** | 勾选本项目包含哪些检测项；报告任务关联现场记录来源 |
| **流程** | 登记五岗参与人（每岗可多人） |
| **分配** | 指定项目主要负责人；向检测员同步任务 |
| **提交** | 查看各任务提交状态，必要时回退 |
| **文件** | 管理本项目关联的文件（部分账号隐藏） |

**页内要点**：
- 许多操作只对 **当前选中的项目** 生效——先选项目再操作
- 任务挂到项目时，**自动同步**已绑定的模板文件，无需手工关联版式
- 支持 **模拟提交**（培训/演示环境），无需真实外业即可走通全流程

**页内要点**：

| 能力 | 说明 |

## 建议页 11｜文件库（数字档案室）

**九大分类**：

| 分类 | 存放内容 | 典型操作 |
|------|---------|---------|
| 模板 | 空白 PDF、坐标 JSON、前端规则 | 编辑模板、试填导出 |

**页内要点**：
- 按委托单位/项目树导航，快速定位某医院某项目的全部资料
- **合并报告**：在报告分类多选 ≥2 份报告，一键生成带统一封面、目录、页眉的总报告
- 回收站提供误删缓冲，批量恢复/彻底删除

## 建议页 12｜模板编辑器

**页内要点**：

| 步骤 | 操作 |
|------|------|
| 1. 载入 | 从文件库选择 PDF，或导入已有 JSON 版式 |
| 2. 划框 | 手动画框 / 自动识别红字区域 / 表格单元格点选 |
| 3. 命名 | 为每个填写区定义字段名（如「CT值_检测结果」） |
| 4. 规则 | 配置公式、判定标准、条件显示、仪器选择等 |
| 5. 映射 | 报告模板配置与现场记录字段的对应关系 |
| 6. 导出 | 保存坐标模板；导出 App 可用的前端 JSON |
| 7. 试填 | 用已有提交数据试生成 PDF，验证版式 |

**亮点能力**：
- **自动红框识别**：减少手工划框工作量
- **报告↔现场映射**：多现场任务时按任务 ID 精确取数，避免串格
- **判定规则内置**：支持 ≥、≤、区间、±允差等标准句式自动判定合格/不合格

**讲稿提示**：版式维护人员无需编程，通过可视化编辑器完成绝大部分配置。

## 建议页 16｜评价报告自动生成（LaTeX·国标）📊 【规划中】

> **状态**：独立模块已设计，**尚未合并入 Django 主平台**；对外可介绍为下一阶段重点建设能力。

### 16.1 功能定位

**页内要点**：
- 面向报告中的 **「评价」章节**及配套正文，解决「多源素材汇总难、国标排版要求高、人工撰写耗时」问题
- 与现有 **PDF 模板回填**（App 提交 → 坐标填表）形成 **双轨成稿**：
  - **轨 A（已上线）**：现场 App 填报 → 按 PDF 模板坐标自动回填检测报告
  - **轨 B（规划中）**：按类别上传 Word/PDF/图片等素材 → 规则提取 → **LaTeX 国标模板**渲染 → 输出评价报告 PDF
- LaTeX 模板按 **国家标准/行业规范文件** 制作，保证章节结构、字体字号、表格版式符合正式出版要求

**讲稿提示**：轨 A 解决「检测数据填进固定表格」；轨 B 解决「把分散在多份文件里的结论与说明，自动汇总成规范排版的评价正文」。二者互补，最终可汇入同一项目的文件库归档。

### 16.3 分类上传界面（核心交互）

用户在上传界面看到的不是「一个大文件夹」，而是 **与评价报告结构一一对应的素材类别清单**。每类说明「应传什么、从哪来、缺了会怎样」。

**典型素材类别（可按报告类型配置）**：

| 类别编号 | 素材类别 | 接受格式 | 用途说明 |
|---------|---------|---------|---------|
| A | 项目基本情况 | Word / PDF | 受检单位、项目名称、设备清单、委托信息 |
| B | 现场原始记录 | PDF | 提取检测条件、仪器信息、原始读数、签字页信息 |
| C | 质量控制检测报告 | PDF | 提取质控检测结果、单项判定、不合格项 |
| D | 工作场所放射防护检测报告 | PDF | 提取防护检测数据、点位结果、本底与评价 |
| E | 设备技术资料 | Word / PDF / 图片 | 设备型号、厂家、主要参数、铭牌照片 |
| F | 平面布局示意图 | 图片 / PDF | 作为附图插入评价报告 |
| G | 现场照片 | 图片（JPG/PNG） | 关键检测点位、工况照片 |
| H | 补充说明材料 | Word | 特殊情况说明、复测记录、客户确认函等 |
| I | 既往评价或整改记录 | Word / PDF | 对比历史结论、引用整改完成情况（可选） |

**页内要点**：
- **一类一格**：每类独立上传区，支持拖拽、多文件、替换与删除
- **进度可视**：显示「已齐备 / 缺 N 项」，缺项时不可发起生成或给出明确提示
- **与项目关联**：素材默认挂到当前检测项目，便于追溯与复用
- **格式包容**：Word（.docx）、PDF、常见图片格式均可；扫描件可走 OCR 辅助提取

**讲稿提示**：业务人员无需理解 LaTeX，只需按界面提示把「做评价报告需要的材料」分门别类传齐即可。

### 16.4 规则提取引擎

后台对每类素材按 **预先设定的提取规则** 解析，输出统一的结构化数据，供 LaTeX 模板消费。

| 提取来源 | 典型规则 | 输出字段示例 |
|---------|---------|-------------|
| 现场记录 PDF | 章节定位（如「五、工作场所放射防护」）、表格行列解析 | 检测条件、仪器编号、读数、报出值 |
| 质控/防护报告 PDF | 节标题锚点、表格「检测结果」「单项判定」列 | 各检测项结果、合格/不合格、限值 |
| Word 文档 | 段落样式、标题层级、书签/占位符 | 单位名称、项目描述、补充说明段落 |
| 图片 | OCR 文字识别、文件名/题注 | 设备铭牌参数、附图编号 |
| 跨素材汇总 | 设备类型归并、台数统计、不合格项聚合 | 评价段首句、设备短语、结论倾向 |

**页内要点**：
- 规则 **可配置**：新报告类型、新版式调整时主要维护映射表与提取脚本，无需改 LaTeX 骨架
- **容错与提示**：某字段提取失败时记录日志，生成前提示人工补录或重新上传
- 与现有 `radiation_detection_report` 等 PDF 表格提取能力 **可复用**（防护检测结果表、判定逻辑等），合并入主平台后统一调度

### 16.5 LaTeX 国标渲染

| 项目 | 说明 |
|------|------|
| **模板依据** | LaTeX 模板按 **国标/行业规范** 编制，覆盖封面要素、章节编号、正文层级、表格、附图、页眉页脚 |
| **排版优势** | 长文档结构稳定、公式与符号规范、分页可控，适合正式检测报告出版级排版 |
| **字体与版式** | 中文宋体、英文 Times 等按标准组合；表格线宽、行距、标题字号符合规范 |
| **编译输出** | `XeLaTeX` / `LuaLaTeX` 编译链 → 输出高质量 PDF，可再与质控/防护报告合并 |
| **模板版本** | 国标修订时单独升级 `.tex` 模板包，历史项目可指定模板版本重生成 |

**评价报告典型章节（示例）**：

```text
封面（受检单位、报告名称、日期）
声明页
一、项目基本情况
二、评价
    （自动汇总：检测概况、设备与结果摘要、合格性判断、建议与结论）
三、（可选）附图与照片索引
附录（可选）
```

**讲稿提示**：LaTeX 保证「版式一次按国标做好、批量生成不跑偏」，避免 Word 手工排版多人多版不一致。

## 附录 D｜双轨成稿对照（建议单独一页 PPT）

| 对比项 | 轨 A：PDF 模板回填（已上线） | 轨 B：评价报告 LaTeX 生成（规划中） |
|--------|---------------------------|----------------------------------|
| **输入** | App 现场结构化填报 JSON | 按类别上传 Word / PDF / 图片等素材 |
| **版式** | PDF 坐标模板（HTMLPDF 编辑器维护） | LaTeX 模板（按国标文件制作） |
| **引擎** | 坐标填表 + 判定规则 | 规则提取 + LaTeX 编译 |
| **主要产出** | 现场记录 PDF、质控/防护检测报告 PDF | 「二、评价」及配套国标排版评价报告 PDF |
| **适用场景** | 现场检测数据填入固定表格 | 多源素材汇总撰写评价章节、正式出版级排版 |
| **典型用户** | 检测员提交 → 系统自动生成 | 编制人上传素材 → 一键生成 → 微调 |
| **与合并报告** | 多份检测报告拼接为总报告 | 评价正文可汇入总报告「二、评价」节 |

**一句话**：轨 A 填「数」；轨 B 写「评」——共同构成完整对外交付能力。
