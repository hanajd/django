# 图　DSA 介入工作流程

```
患者情况调查、登记 → 介入放射风险告知及可能受到的辐射危害
        ↓
介入放射正当性判断
   ├─ 未通过 → 不进行放射介入实践
   └─ 通过 → 制定诊疗计划、确定时间 → 预约登记、候诊
        ↓
医务人员、患者术前准备（穿戴相应防护用品等）
        ↓
患者进入机房、摆位
        ↓
技师隔室操作：曝光摄影、图像采集（产生 X 射线）
        ↓
介入医师进入机房：脉冲透视并输送造影导管（产生 X 射线）
        ↓
介入医师退出；技师隔室加压输送造影剂、摄影减影分析（产生 X 射线）
        ↓
工作人员同室近台操作、间歇透视：开展介入手术或检查（产生 X 射线）
        ↓
手术完毕、开启防护门，离开机房
```
