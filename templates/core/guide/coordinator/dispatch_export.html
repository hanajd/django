分工与报告导出

本篇说明委托统筹从人员分工到导出现场记录 → 导出报告 → 多份报告合并交付的完整操作路径。界面按钮以实际文案为准，下文 紫底 为常见按钮名。

一、全流程（先建立整体顺序）

  1. 项目工作台 → 委托立项：挂载受检设备与本次检测类型。
  2. 项目工作台 → 人员派工：指定统筹人、登记五类流程岗位参与人（登记后自动向 App 同步任务）。
  3. 项目工作台 → 仪器管理（若项目需要）：分配检测仪器；状态与台账联动见 检测仪器台账。
  4. 检测员等在 App 填报并提交 → 资料进入 文件库管理 → 检测提交。
  5. 文件库 → 检测提交：勾选数据，点 手动导出 PDF → 生成 现场记录。
  6. 校核员等在 App 完成校核；现场记录齐备后，在文件库 导出报告（见第三节）。
  7. 编制 / 审核 / 签发岗位在 App 完成各自环节（见「检测流程岗位」）。
  8. 多台设备需合订交付时：文件库 → 报告 → 勾选多份单台报告 → 报告合并。

记忆：先派工 → App 提交 → 导出现场记录 → 导出报告 → 必要时合并多份报告 PDF。

二、人员分工（项目工作台 · 人员派工）

入口：项目工作台 → 左侧选中项目 → 顶栏 人员派工 标签。

2.1 项目统筹人

  • 在「项目统筹人」区域单选一名用户，点 确认指定统筹人。
  • 统筹人负责本项目工作台内的配置与协调（每项目一名）。

2.2 流程岗位参与人（核心分工）

按岗位等级由低到高：检测员 → 校核员 → 编制人 → 审核人 → 授权签字人。高权限账号可兼任不高于自身等级的岗位。

  1. 展开对应岗位下的 添加人员到「检测员」（或校核员、编制人等）。
  2. 勾选一名用户，点 确认添加到「××」。
  3. 同一岗位可登记多人；新增不会替换该岗位已有人员。
  4. 登记成功后系统自动同步 App 任务；检测员登录 App 方能在待办中看到本项目。

人员账号须先在 用户管理 中创建，岗位角色与登记一致。移除人员会撤回其在本项目上的 App 任务同步。

2.3 任务同步概览

  • 页面下方「任务同步概览」可查看已向谁同步了哪些模板、同步时间与撤回操作。
  • 若 App 无待办：核对是否已登记该人、是否用本人账号登录、委托立项 是否已挂载设备与检测类型。

三、导出现场记录 PDF

前提：检测员已在 App 提交，文件库管理 → 检测提交 中能看到对应项目的 JSON / 附件。

  1. 进入 文件库管理，点左侧分类 检测提交。
  2. 在列表中按检测项目 → 报告环节 → 现场记录环节展开，定位到目标记录（可用页内检索）。
  3. 勾选需要导出的检测提交行，或勾选分组行首复选框选中整段分支。
  4. 点列表上方 手动导出 PDF，确认后系统生成现场记录 PDF，写入 现场记录 分类。

提示：同现场记录下若有多版 JSON，导出时系统通常仅取最新一条。文件名建议含项目、任务说明及任务编号，便于后续报告导出识别。

四、导出报告 PDF

一份报告常汇总多份现场记录（多表、多环节）；单台设备对应一份报告。下列三种方式按场景选用（均需具备导出权限，按钮不可见时请读页顶说明）。

4.1 按报告环节一键导出（推荐，无需勾选）

适用于 检测提交 / 现场记录 的文件夹分组视图。

  • 展开到某一报告环节行，点右侧 导出合并报告：系统自动取该报告下各现场记录环节最新一条（优先 PDF，无则回退检测提交 JSON），按模板映射合并为一份报告 PDF，写入 报告 分类。
  • 若只需单个现场记录环节：展开到现场记录环节行，点 导出报告（或进入该文件夹后点 导出报告（本环节最新））。

4.2 勾选后手动导出报告

  1. 在 检测提交 或 现场记录 分类中，勾选一条或多条记录（多份时按合并规则汇总为一份报告数据）。
  2. 点列表上方 手动导出报告，确认后生成报告 PDF 到 报告 分类。

多份勾选时，同一业务块（如医院信息）一般以先勾选者为准；请优先使用系统导出的标准现场记录 PDF。

五、合成 / 合并报告（多台设备合订本）

与第四节「导出报告」不同：本节是把已生成的多份单台设备报告 PDF 拼成一本带目录的合订 PDF，用于对外交付或分科室套装。

  1. 进入 文件库管理 → 报告 分类。
  2. 勾选至少 2 份报告 PDF（须为各设备原始单台报告，勿选已合并过的大文件）。
  3. 点 报告合并，确认后系统生成带目录页的合并稿（章节名来自各 PDF「三、检测结果」中的设备信息）。
  4. 打开合并稿目检目录：设备名、1.1 / 2.1 等小节与页码是否合理；异常时回到单台报告修正后重新导出再合并。

勿混淆：导出合并报告（第四节）是把多份现场记录/提交合成一份报告；报告合并（本节）是把多份报告 PDF 合成一本合订 PDF。

六、与进度跟踪的衔接

  • 项目工作台 → 进度跟踪：查看各检测项提交与签字进度，确认可导出前流程岗位是否已完成。
  • 委托管理：纵览委托完成度；细节操作仍回项目工作台与文件库。

七、常见问题

  • 导出按钮灰色或不存在：未勾选文件、分类不对、App 未提交、或无导出权限。
  • 手动导出 PDF 无结果：检测提交分类无数据 → 先完成 App 提交与人员派工。
  • 报告合并目录异常：输入须为单台原始报告；维护好 医院信息管理 中的设备名称与型号。

小结：本篇回答的是——「谁做什么岗位、现场记录怎么导、报告怎么出、多份报告怎么合订交付」在后台的具体点击顺序。
