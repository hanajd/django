# 拟合公式 + R²：前端对接说明

后台只下发配置；**系数与 R² 均在前端算**。条件公式约定见 [`条件公式与前端type约定.md`](./条件公式与前端type约定.md)。

---

## 1. 两个栏位（及「仅源」变体）

| | 拟合公式（主格 / 源） | R²（从格） | 引用格（系数 / 正反算） |
| --- | --- | --- | --- |
| 识别 | `type: computed` + `fitBinding`；出方程时再加 `displayFormat: "latex"` | `type: computed` + 普通算术式（含 `ln`）或 `fit_r2(源)` | `type: computed` + **展开算术式**（与 R² 同类；编辑器/导出由 `fit_a/b/y/x` 生成） |
| `expression` | `fit(y=...)` 待定系数模型（在 `formulaRules`） | 已展开的 Pearson 式，或 `fit_r2(f源)` | 见 §7 |
| 展示 | 方程（latex）或**不展示**（`fitBinding.output: "none"`） | 数值 | 数值或方程字符串 |

主格 `fitBinding.r2FieldId` 指向 R² 栏；R² 可镜像同组 `x`/`y`，其 `r2FieldId` 为空。

**只要系数、不要方程**：在任意格配置拟合并勾选「仅作拟合源」→ `fitBinding.output = "none"`（本格清空 `formula` / 不用 latex）。**不需要另设可见方程主格**；其它格在「调用拟合源」里选用后，写入的是**展开计算公式**（不是留下 `fit_x(...)` 给平板解析）。

---

## 2. 下发 JSON（胃肠机实样精简）

**主格**

```json
{
  "id": "f1242",
  "type": "computed",
  "displayFormat": "latex",
  "fitBinding": {
    "x": ["f179", "f180", "f181", "f182", "f183"],
    "y": ["f195", "f196", "f197", "f198", "f199"],
    "r2FieldId": "f200",
    "output": "equation",
    "modelConditions": { "linear": "f1238", "log": "f1071", "exp": "f1072" }
  },
  "formulaRules": [
    { "label": "线性", "condition": "f1238", "expression": "fit(y=a*x+b)" },
    { "label": "对数", "condition": "f1071", "expression": "fit(y=a*ln(x)+b)" },
    { "label": "指数", "condition": "f1072", "expression": "fit(y=a*exp(b*x))" }
  ],
  "formula": "if(f1238,fit(y=a*x+b),if(f1071,fit(y=a*ln(x)+b),if(f1072,fit(y=a*exp(b*x)),\"\")))"
}
```

**仅源（不输出方程）**

```json
{
  "id": "f1242",
  "type": "computed",
  "fitBinding": {
    "x": ["f179", "f180", "f181", "f182", "f183"],
    "y": ["f195", "f196", "f197", "f198", "f199"],
    "r2FieldId": "f200",
    "output": "none"
  },
  "formulaRules": [
    { "label": "线性", "condition": "f1238", "expression": "fit(y=a*x+b)" }
  ],
  "formula": ""
}
```

**系数 / 反算引用格**

```json
{
  "id": "f1301",
  "type": "computed",
  "precision": 2,
  "formula": "fit_a(f1242)"
}
```

```json
{
  "id": "f1302",
  "type": "computed",
  "formula": "fit_x(f1242, f1290)"
}
```

**R²**（`expression` 为完整展开式，此处省略中间项）

```json
{
  "id": "f200",
  "type": "computed",
  "fitBinding": {
    "x": ["f179", "f180", "f181", "f182", "f183"],
    "y": ["f195", "f196", "f197", "f198", "f199"],
    "r2FieldId": ""
  },
  "formulaRules": [
    { "label": "线性", "condition": "f1238", "expression": "((((5)*((f179)*(f195)+...))))" },
    { "label": "对数", "condition": "f1071", "expression": "((((5)*((ln(f179))*(f195)+...))))" },
    { "label": "指数", "condition": "f1072", "expression": "((((5)*((f179)*(ln(f195))+...))))" }
  ],
  "judgmentCriteriaByTestType": { "acceptance": ">=0.98", "status": ">=0.95" }
}
```

点列：`fitBinding.x[i]` 与 `y[i]` 一对。未写 `precision` 时：**拟合主格（方程系数）按 3**，其余栏位按 **2**。主格未显式配置时导出会自动写入 `precision: 3`，与检测机构 Excel 趋势线的 3 位系数对齐。

## 3. 前端怎么算

与其它 `computed` 相同：按 `formulaRules` 取**首个 `condition` 为真**的规则（全空则下选 / 单条直接用）。

| 命中 `expression` | 做法 |
| --- | --- |
| `fit(y=a*x+b)` | 读有效点 ≥2 → OLS → 写方程（若 `output≠none`） |
| `fit(y=a*ln(x)+b)` | 要求 x>0；对 `(ln x, y)` OLS |
| `fit(y=a*exp(b*x))` | 要求 y>0；对 `(x, ln y)` OLS，再 `a = exp(ln a)` |
| 引用格展开式 | 见 §7：导出/插入时写成 OLS 闭式算术（含 `ln`/`exp`），**不要**依赖平板识别 `fit_x(...)` |
| 其它（R²） | 当普通公式求值（需支持 `ln`、`exp`、`if`） |

**主格未勾选、或有效点不足 / 不满足符号约束 → 清空结果，勿写假方程。**  
R² 无公式下拉；与主格同条件重算即可。

依赖变化即重算：`x`/`y` 各栏、各 `condition` 勾选框、以及引用格依赖的源。

---

## 4. 方程展示（代入 a、b 后）

| 模型 | `equationLatex` |
| --- | --- |
| `fit(y=a*x+b)` | `y = {a}x + {b}`（b&lt;0 用减号） |
| `fit(y=a*ln(x)+b)` | `y = {a}\ln x + {b}` |
| `fit(y=a*exp(b*x))` | `y = {a}{\rm e}^{{b}x}`（e 必须正体） |

系数按栏位 `precision` 舍入，**拟合主格默认 3 位**（`utils.pdf_field_formulas.FIT_EQUATION_COEFFICIENT_PRECISION`）。舍入只作用于**展示的方程字符串**，不得回过头影响任何数值计算（见 §8）。

## 5. 提交

```json
{
  "f1242": "y = 1.23x + 0.45",
  "f200": 0.99,
  "f1301": 1.23,
  "f1302": 2.45
}
```

主格至少交方程字符串（可用 `equationLatex` / `$$…$$`）；`output: none` 的源格可不交或交空。R² / 系数 / 正反算交数值。

现场记录 PDF 导出时：**仅当提交值为整段 `$$…$$`**（拟合主格方程，如 `$$y = 1.23x + 0.45$$`）才经 **MathJax** 渲染成公式图叠印。模板侧仅拟合主格应带 `displayFormat: "latex"`（见 `utils.pdf_field_formulas.is_fit_equation_latex_field`）；R² / 普通数值即使误标也不再走公式图。失败时回退 matplotlib mathtext。

---

## 6. 注意

- 不要把 `fit(...)` 当 `avg(...)` 算术解析。
- 无 `fitKind` / 旧无参 `fit_eq()` 优先迁成 `fit(y=...)`。整格输出方程用新函数 **`fit_eq(源)`**（勿与旧无参 `fit_eq()` 混淆）。
- 算术引擎需支持：`if`、`ln`、`exp`、四则与括号。

---

## 7. 拟合引用 → 展开为可求值公式（与 R² 同策略）

编辑器里点「调用拟合源」时，**不要把 `fit_x(f990, f215)` 原样留给平板**。应像 f214 的 Pearson R² 一样，按源的 X/Y 与模型写成闭式算术（`utils/fit_ref_expand.py` / 编辑器同逻辑）。

| 用途 | 展开结果 |
| --- | --- |
| 系数 a / b | OLS 斜率/截距闭式（指数模型 a 为 `exp(截距)`） |
| 用 x 求 y | 线性 `a*x+b`；对数 `a*ln(x)+b`；指数 `exp(斜率*x+截距)` |
| 用 y 求 x | 线性 `(y-b)/a`；对数 `exp((y-b)/a)`；指数 `(ln(y)-截距)/斜率` |
| 输出方程 | 仍可用 `fit_eq(源)`（字符串，非整式数值） |

多模型时：按源的 `formulaRules`（条件/标签）各写一条展开规则，与 R² 三条规则镜像方式一致。

编辑器在拟合面板提供绿色 **模型选用条件**（线性/对数/指数各绑一个勾选框，写入 `fitBinding.modelConditions` 并同步到各 `formulaRules.condition` 与 R²）。同一套 X/Y 只配一次，不必在每条规则里重复填。

导出后处理：`frontend_schema_rule_engine` 会把残留的整式 `fit_a/b/y/x(...)` 自动展开。后台求值若仍遇到紧凑写法，`utils/fit_ref_eval.py` 可兼容。

算术引擎需支持：`if`、`ln`、`exp`、四则与括号。

**展开式是快照，会过期。** 主格改了 `fitBinding.x/y` 之后，R² 与引用格里已经写死的算术式仍指向旧点列。点数变少时 Pearson 会退化（**2 点恒等于 1**，现场表现为 R² 一直是 1.000）。编辑器 `syncFitR2RuleExpressions` 与导出侧 `utils.pdf_field_formulas.sync_fit_r2_rule_expressions` 会比对公式里 f 号的出现次数，与 `fitBinding` 对不上就按点列重算；出现次数一致时不动，故 `round(...,3)` 这类二次编辑会被保留。引用格（`fit_a/b/y/x` 展开式）目前没有同类自检，改点列后需手动重新「调用拟合源」。

---

## 8. 链式计算必须用全精度中间值（平板端）

`precision` 只是**显示位数**，不是存储精度。中间计算格（如用拟合方程反算出来的"换算成剂量值"）若按 `precision` 四舍五入后再参与下一级公式，误差会被放大到肉眼可见。

现场实例：均匀性 5 点 PV = 451/460/444/451/459，拟合系数 a=52.43326633、b=−49.84344816，反算剂量 = (PV−b)/a。

| 参与 CV 计算的值 | CV |
| --- | --- |
| 9.552017, 9.723664, 9.418514, 9.552017, 9.704592（全精度） | 1.3116% → **1.31**（正确） |
| 9.55, 9.72, 9.42, 9.55, 9.70（先按 precision=2 取整） | 1.2888% → **1.29**（偏小） |

约定：

- 计算图里每个节点**保存并向下传递全精度 double**，`precision` 只在渲染和提交展示值时应用；
- 提交 JSON 里数值格可以是取整后的展示值，但**不得用它回填内存中的计算值**；
- 拟合方程字符串（3 位系数）只用于展示，下游正算 / 反算一律走下发的展开式或全精度 a、b；
- 后台 `_apply_computed_fields_from_steps_to_mapping` 已按全精度求值，仅补提交里缺失的键，不会二次取整。
