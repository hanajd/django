整体工作顺序

现场检测类业务在后台里通常拆成几条线：项目是谁的、做哪些检测、资料与版式放在哪、谁去填与审、最后形成记录和报告。下面按「时间顺序 + 菜单对应关系」说明，便于您把界面和真实工作对上号。

一、业务主线（心里先有这张图）

实际流程多为：确定项目 → 明确检测项 → 准备模板与附件 → 现场或线上填报 → 形成现场记录 → 再形成对外报告。后台左侧大致为 项目工作台 → 文件库 / 任务模板库 →（填报与导出）→ 记录与报告相关能力，不必一次全弄懂，按项目推进即可。

二、每一步在后台里对应什么

  1. 先选项目
    左侧进入 项目工作台，在列表中点选当前要操作的项目。多数列表、分配相关页签、挂任务都只对「当前选中项目」生效。若未选项目就去找文件或任务，往往看到空列表或灰色按钮。
  2. 把检测任务挂到项目上
    在同一页面将本单位要做的标准检测勾选到本项目，并点击页面上的 保存 / 确认类按钮（具体文案以界面为准）。含义是：告诉系统「这个项目包含哪些检测项」。未勾选的任务，后续模板选择、流程、导出可能不会出现或会报错。
  3. 准备资料（文件库）
    进入 文件库管理，上传空白 PDF、JSON 模板、现场照片等，并按顶部分类 模板、现场记录、报告、附件 等存放。需要画版式或试填时，在「模板」列表中点击某 PDF 旁的 编辑模板 进入 模板编辑器。
  4. 定版式与仪器（任务模板库）
    进入 任务模板库，维护「每种检测长什么样」：绑定文件库里的版式、设置默认仪器、使用 试导出 等核对 PDF。若点击了 新建 增加模板类型，必须回到 项目工作台 把新任务再勾进本项目并保存，否则系统不知道哪个项目要用它。
  5. 填报与模板编辑器（若账号具备权限）
    在 模板编辑器 中为 PDF 划定填写区并 保存坐标模板 JSON 等；或在其他业务页完成检测数据填报。试填后可 导出已填写 PDF，并在下拉中选择写入 现场记录 或 报告（详见「模板编辑器」专篇）。
  6. 现场记录与报告
    数据与现场结果齐备后，按单位流程生成或导出现场记录，再进入报告环节。业务上常见关系是：同一项目下有多台设备则往往多份报告；单份报告常汇总多份现场记录；若项目对接多个科室、各科不必使用全部报告，可在 文件库 的 报告 分类下用 多选 + 合并 等能力做组合交付（详见专篇「现场记录与报告」第一节）。

三、建议阅读顺序

第一次使用：先读本篇建立整体图，再依次打开本站内 项目工作台、文件库、任务模板库 各篇细看；需要画 PDF 时再读 模板编辑器 专篇；最后浏览「现场记录与报告」与「常见情况与排查」。

小结：整体顺序回答的是——「从选项目到出报告，中间每一步在后台点哪里、先做什么」。
