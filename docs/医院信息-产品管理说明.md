# 医院信息 · 产品管理与委托销售挂载

本文说明「产品管理」目录能力，以及在医院信息中如何把**销售产品**挂到委托、再挂设备与检测。与「委托直接挂设备」并存，产品侧主要用于**销售情况记录**。

## 入口

| 位置 | 路径 / 操作 |
|------|-------------|
| 医院信息管理右上角 | **产品管理** → `/files/hospital-info/products/` |
| 医院信息详情 | 选中医院（或下属机构）后，右侧 **委托信息** 卡片 |
| 初始化示例数据 | 产品管理页「初始化示例产品」，或 `python manage.py seed_sales_products` |

权限与医院信息管理一致：需文件库权限，且角色可访问医院信息导航；写操作需医院信息编辑权限。

## 数据层级

```
医院（CommissionOrganization）
 └─ 委托项目（LibraryProject，commission_org = 医院根）
     ├─ 直挂设备（LibraryProjectEquipment）……原有能力，保留
     └─ 销售产品（LibraryProjectProduct）……新增，记销售
           └─ 产品下设备+检测（LibraryProjectProductEquipment）
```

产品**目录**独立于某家医院，在「产品管理」维护；挂到某委托后才成为该次委托的销售记录（含数量、成交单价快照）。

## 产品管理功能

页面 Tab：

1. **产品**：增删改、搜索、上下架、**上架时间**、标准价格/单位、分类与产品线、负责人、备注、规格属性；勾选**默认设备类型**（可多选，并为每类设置**台数**）、**默认检测类型**。
2. **分类**：添加 / 删除（分类下仍有产品时不可删）。
3. **产品线**：添加 / 删除（同理）。
4. **修改日志**：`BizOperationLog`，`scope=product`，记录产品/分类/产品线变更摘要与详情。

列表在右侧卡片内滚动，页面整体一屏展示，不撑长整页。

字段对应业务表格常见列：产品名称、标准价格、单位、上下架、上架时间、分类、产品线、负责人、备注、创建时间、规格属性。

> 说明：完整目录初始化请用运维命令 `python manage.py seed_sales_products`（读取 `apps/core/data/sales_products_catalog.json`），产品管理页日常不再放「同步」按钮。

## 医院信息中的委托挂载

在 **编辑** 模式下：

1. 打开某医院节点 → **委托信息** 展开委托。
2. **添加销售产品**：选择已上架目录产品，可填数量与单价（空则用标准价）。
3. 在产品卡片上 **挂载** 本医院树下设备 + 检测类型（验收检测 / 状态检测等）。
4. 可移除产品或解除单条设备挂载。

浏览模式下仅查看。下方 **单位设备** 与「加入项目」等直挂流程不变。

## 模型一览

| 模型 | 说明 |
|------|------|
| `SalesProductCategory` | 分类 |
| `SalesProductLine` | 产品线 |
| `SalesProduct` | 产品目录（含 `default_device_types` / `default_inspection_types` JSON） |
| `LibraryProjectProduct` | 委托上的销售行（数量、成交单价） |
| `LibraryProjectProductEquipment` | 销售行下的设备 + 检测类型 |
| `BizOperationLog.SCOPE_PRODUCT` | 产品目录操作日志范围 |

服务：`apps/core/sales_product_service.py`  
视图：`apps/core/product_catalog_views.py`（目录页）、`hospital_info_manage` POST actions（委托挂载）  
迁移：`apps/core/migrations/0064_sales_product_catalog.py`

## 与直挂设备的关系

- **直挂**：项目工作台 / 医院设备「加入项目」→ `LibraryProjectEquipment`，驱动任务模板与检测作业。
- **销售产品**：记录卖了什么、单价数量，并可把设备/检测挂在产品下做销售侧对照；**不替代**直挂，也不自动改写项目任务列表。

## 运维提示

- 首次上线：执行迁移至 `0065_sales_product_listed_at_device_counts`，再视需要 `seed_sales_products`（读取 `apps/core/data/sales_products_catalog.json`，当前约 53 条完整目录）。
- 产品目录日常维护在「产品管理」页完成；全量种子同步仅用管理命令。
- 已挂到委托的产品不可硬删目录项，请先下架或先解除委托挂载。
- 日志 API：`GET /files/biz-operation-logs/?scope=product`（可选 `entity_id=` 过滤某产品）。
