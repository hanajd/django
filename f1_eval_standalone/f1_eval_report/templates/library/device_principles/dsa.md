# DSA工作原理

DSA工作原理：DSA是由「C型臂」、数字平板探测器、球管、束光器、专业手术床、计算机机柜以及图像处理系统组成。DSA基本原理和技术为：是通过电子计算机进行辅助成像的血管造影方法，其应用计算机程序进行两次成像完成。在注入造影剂之前，首先进行第一次X射线成像，并用计算机将图像转换成数字信号储存起来。注入造影剂后，再次成像并转换成数字信号，再经减影、对比度增强和数/模转换，产生数字减影图像。利用平板C臂DSA系统类CT模式下进行旋转成像，获得类似CT的图像，而无需将患者移送到CT/MRI检查室，以便能够及时、有效地掌握病情，指导正确的治疗与救治方案，为进一步治疗争取了宝贵的时间。
