医院信息管理

入口：左侧 医院信息管理。用于维护受检单位的组织结构与设备台账，供 项目工作台 立项、App 填报及报告生成时引用。委托统筹账号可直接新建与编辑，无需先点「进入编辑模式」。

一、页面结构

  • 左侧树：医院 → 院区 → 科室，点击节点在右侧查看详情。
  • 右侧详情：机构基本信息、受检设备列表（可挂在医院 / 院区 / 科室）。
  • 顶栏或详情区提供 新建医院、新建院区、新建科室、新建设备 等入口（以界面为准）。

二、推荐维护顺序

  1. 新建医院：填写单位名称、地址、联系人等（字段以表单为准）。
  2. 新建院区：同一医院下若有多个院区，分别建立。
  3. 新建科室：在对应院区下建立科室节点。
  4. 登记设备：可在医院、院区或科室下添加受检设备（科室可选）；务必填写设备名称、型号、额定参数等；这些信息会出现在报告与合并目录中。

三、编辑已有信息

  • 在详情区点击 编辑 可修改机构信息或设备资料。
  • 设备搬迁到其他科室时，应在系统中调整归属，避免立项时挂错科室。
  • 已用于历史项目的设备信息修改后，新生成的报告会使用新数据；已归档 PDF 不会自动变更。

四、与立项、报告的关系

  • 在 项目工作台 新建委托 时，从本模块已维护的医院/科室/设备中选择，减少手工录入错误。
  • 报告 PDF 中的「设备名称」「型号」等优先来自检测数据与设备登记；信息不全时合并报告目录可能显示为「检测设备」，维护好本页可减少此类问题。

小结：医院信息管理回答的是——「受检单位与设备台账在哪里维护、立项前要先建好什么」。
