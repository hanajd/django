\chapter{结论与建议}

\section{评价结论}

\begin{enumerate}
\item 本项目为改建严重危害类放射项目，使用$^{192}\text{Ir}$Ⅲ 类密封源，合规；
\item 机房布局、分区、迷道设置符合国标；原有屏蔽厚度富余，墙外辐射剂量远低于控制值；
\item 安全联锁、报警、通风、应急储源、视频对讲等防护设施全部达标；
\item 院内 + 第三方双重监测方案满足法规；工作人员、公众受照剂量远低于内控及国标限值；
\item 应急体系、防护管理组织、制度、人员健康管理满足规范；
\end{enumerate}
\textbf{综合结论：项目在落实本报告建议前提下，放射职业病危害防控可行，具备卫生审批条件。}

\section{整改建议}

\begin{enumerate}
\item 所有新购置质控仪器投入使用前法定计量检定，落实日常自检记录；
\item 设备进场后完善专项操作规程、应急预案、患者告知书并上墙；
\item 新增放射人员必须完成岗前培训、体检、个人剂量建档；
\item 取得卫健部门预评价批复后方可施工改造；完工后做控制效果评价、换发放射诊疗许可；
\item 机房布局、源活度重大变更须重新开展预评价。
\end{enumerate}
