# 拟合公式 + R²：前端对接说明

后台只下发配置；**系数与 R² 均在前端算**。条件公式约定见 [`条件公式与前端type约定.md`](./条件公式与前端type约定.md)。

---

## 1. 两个栏位（及「仅源」变体）

| | 拟合公式（主格 / 源） | R²（从格） | 引用格（系数 / 正反算） |
| --- | --- | --- | --- |
| 识别 | `type: computed` + `fitBinding`；出方程时再加 `displayFormat: "latex"` | `type: computed` + 普通算术式（含 `ln`）或 `fit_r2(源)` | `type: computed` + **展开算术式**（与 R² 同类；编辑器/导出由 `fit_a/b/y/x` 生成） |
| `expression` | `fit(y=...)` 待定系数模型（在 `formulaRules`） | 已展开的 Pearson 式，或 `fit_r2(f源)` | 见 §7 |
| 展示 | 方程（latex）或**不展示**（`fitBinding.output: "none"`） | 数值 | 数值或方程字符串 |

主格 `fitBinding.r2FieldId` 指向 R² 栏；R² 可镜像同组 `x`/`y`，其 `r2FieldId` 为空。

**只要系数、不要方程**：在任意格配置拟合并勾选「仅作拟合源」→ `fitBinding.output = "none"`（本格清空 `formula` / 不用 latex）。**不需要另设可见方程主格**；其它格在「调用拟合源」里选用后，写入的是**展开计算公式**（不是留下 `fit_x(...)` 给平板解析）。

## 3. 前端怎么算

与其它 `computed` 相同：按 `formulaRules` 取**首个 `condition` 为真**的规则（全空则下选 / 单条直接用）。

| 命中 `expression` | 做法 |
| --- | --- |
| `fit(y=a*x+b)` | 读有效点 ≥2 → OLS → 写方程（若 `output≠none`） |
| `fit(y=a*ln(x)+b)` | 要求 x>0；对 `(ln x, y)` OLS |
| `fit(y=a*exp(b*x))` | 要求 y>0；对 `(x, ln y)` OLS，再 `a = exp(ln a)` |
| 引用格展开式 | 见 §7：导出/插入时写成 OLS 闭式算术（含 `ln`/`exp`），**不要**依赖平板识别 `fit_x(...)` |
| 其它（R²） | 当普通公式求值（需支持 `ln`、`exp`、`if`） |

**主格未勾选、或有效点不足 / 不满足符号约束 → 清空结果，勿写假方程。**  
R² 无公式下拉；与主格同条件重算即可。

依赖变化即重算：`x`/`y` 各栏、各 `condition` 勾选框、以及引用格依赖的源。

---

## 4. 方程展示（代入 a、b 后）

| 模型 | `equationLatex` |
| --- | --- |
| `fit(y=a*x+b)` | `y = {a}x + {b}`（b&lt;0 用减号） |
| `fit(y=a*ln(x)+b)` | `y = {a}\ln x + {b}` |
| `fit(y=a*exp(b*x))` | `y = {a}{\rm e}^{{b}x}`（e 必须正体） |

系数建议按栏位 `precision`（默认 2）舍入。

---

## 5. 提交

```json
{
  "f1242": "y = 1.23x + 0.45",
  "f200": 0.99,
  "f1301": 1.23,
  "f1302": 2.45
}
```

主格至少交方程字符串（可用 `equationLatex` / `$$…$$`）；`output: none` 的源格可不交或交空。R² / 系数 / 正反算交数值。

现场记录 PDF 导出时：`displayFormat: "latex"` 或整段 `$$…$$` 会经 **MathJax** 渲染成公式图，再按栏位坐标叠印（失败时回退 matplotlib mathtext）。

---

## 6. 注意

- 不要把 `fit(...)` 当 `avg(...)` 算术解析。
- 无 `fitKind` / 旧无参 `fit_eq()` 优先迁成 `fit(y=...)`。整格输出方程用新函数 **`fit_eq(源)`**（勿与旧无参 `fit_eq()` 混淆）。
- 算术引擎需支持：`if`、`ln`、`exp`、四则与括号。

---

## 7. 拟合引用 → 展开为可求值公式（与 R² 同策略）

编辑器里点「调用拟合源」时，**不要把 `fit_x(f990, f215)` 原样留给平板**。应像 f214 的 Pearson R² 一样，按源的 X/Y 与模型写成闭式算术（`utils/fit_ref_expand.py` / 编辑器同逻辑）。

| 用途 | 展开结果 |
| --- | --- |
| 系数 a / b | OLS 斜率/截距闭式（指数模型 a 为 `exp(截距)`） |
| 用 x 求 y | 线性 `a*x+b`；对数 `a*ln(x)+b`；指数 `exp(斜率*x+截距)` |
| 用 y 求 x | 线性 `(y-b)/a`；对数 `exp((y-b)/a)`；指数 `(ln(y)-截距)/斜率` |
| 输出方程 | 仍可用 `fit_eq(源)`（字符串，非整式数值） |

多模型时：按源的 `formulaRules`（条件/标签）各写一条展开规则，与 R² 三条规则镜像方式一致。

编辑器在拟合面板提供绿色 **模型选用条件**（线性/对数/指数各绑一个勾选框，写入 `fitBinding.modelConditions` 并同步到各 `formulaRules.condition` 与 R²）。同一套 X/Y 只配一次，不必在每条规则里重复填。

导出后处理：`frontend_schema_rule_engine` 会把残留的整式 `fit_a/b/y/x(...)` 自动展开。后台求值若仍遇到紧凑写法，`utils/fit_ref_eval.py` 可兼容。

算术引擎需支持：`if`、`ln`、`exp`、四则与括号。
