# 后台系统使用说明（driver\.js交互优化版）

说明：本次优化基于原有业务逻辑，通过driver\.js添加分步交互引导，帮助用户快速熟悉后台操作流程，降低学习成本。以下文档包含「交互引导逻辑」「driver\.js配置规范」「分模块交互实现代码」三部分，可直接交付agent落地实现，所有引导均贴合原有业务步骤，不改变核心操作流程。

# 一、整体交互设计原则

1\.  引导优先级：按「业务流程顺序」（确定项目→检测项→资料准备→填报→记录→报告）分步引导，贴合用户实际操作习惯；

2\.  交互逻辑：首次登录/首次进入某模块时触发引导，引导可手动关闭（提供「跳过引导」「下一步」「上一步」按钮），关闭后可通过页面「帮助」按钮重新触发；

3\.  视觉规范：引导浮层统一风格（默认driver\.js原生样式，可按单位UI规范微调），高亮当前操作元素，引导文案简洁明了，贴合原有说明的核心要点；

4\.  权限适配：引导内容随用户权限动态调整（如无「任务模板库」权限的用户，不触发该模块引导）。

# 二、driver\.js基础配置（全局通用）

提前引入driver\.js资源（CDN或本地引入），配置全局默认参数，确保所有引导风格统一，agent可直接复用该配置。

```javascript
// 全局driver.js配置（agent直接复制使用）
import driver from 'driver.js';
import 'driver.js/dist/driver.css';

// 全局默认配置
const driverConfig = {
  overlayColor: 'rgba(0, 0, 0, 0.5)', // 遮罩层颜色
  opacity: 0.7, // 遮罩层透明度
  padding: 10, // 高亮元素内边距
  allowClose: true, // 允许点击遮罩关闭引导
  closeBtnText: '跳过引导', // 关闭按钮文字
  nextBtnText: '下一步', // 下一步按钮文字
  prevBtnText: '上一步', // 上一步按钮文字
  doneBtnText: '完成引导', // 完成按钮文字
  showButtons: true, // 显示操作按钮
  showProgress: true, // 显示引导进度（如 1/5）
  keyboardControl: true, // 支持键盘方向键切换引导
  onClose: () => {
    // 引导关闭回调：记录用户已跳过，下次进入不自动触发（可结合本地存储实现）
    localStorage.setItem('guideClosed', 'true');
  }
};

// 初始化引导实例
const guideDriver = new driver(driverConfig);
```

function initCommonProblemGuide() {

## 2\. 代码适配

（1）将上述所有代码中的「替换为实际选择器」替换为后台系统对应DOM的选择器（如id、class、标签选择器），确保能精准定位元素；

（2）权限判断逻辑（如hasTemplatePermission）需替换为系统实际的权限接口返回值，确保无权限用户不触发对应引导；

（4）引导浮层样式可根据单位UI规范，修改driverConfig中的overlayColor、padding等参数，或自定义CSS覆盖默认样式。

## 3\. 触发时机配置

（1）整体流程引导：在系统登录成功后执行initOverallGuide\(\)；

（2）模块引导：在对应模块页面加载完成后执行（如项目工作台页面加载后执行initProjectWorkbenchGuide\(\)）；

（3）现场记录/报告引导：在「生成记录」「生成报告」按钮点击事件中，先执行initRecordReportGuide\(type\)，再执行导出逻辑；

（4）常见问题引导：在页面加载完成后执行initCommonProblemGuide\(\)，监听异常状态。

## 4\. 补充说明

（1）引导可重复触发：所有引导在用户完成后，可通过页面添加「帮助」按钮，点击按钮重新触发对应模块引导（如点击「项目工作台帮助」，执行initProjectWorkbenchGuide\(\)）；

（2）兼容性：driver\.js支持主流浏览器（Chrome、Firefox、Edge等），无需额外适配；

（3）优先级：若多个引导同时满足触发条件，优先触发「业务流程靠前」的引导（如整体流程引导优先于模块引导）。
