整体工作顺序

委托统筹负责在精简后台中完成「委托单位资料 → 团队账号 → 立项派工 → 进度跟踪 → 资料归档与报告交付」。与演示账号（test）不同，您没有 任务模板库、模板编辑器、文档识别 等版式维护入口；检测版式由单位预先配置，您直接使用全部标准任务模板立项即可。

一、您能看到哪些菜单

  • 文件库管理：待识别文件、现场记录、报告、附件、检测提交、回收站（无「数据文件」「模板」分类）。
  • 项目工作台：选项目、挂检测任务、登记流程岗位、向参与人同步任务。
  • 委托管理：查看委托进度、消息提醒、按人员汇总（立项细节仍在项目工作台）。
  • 医院信息管理：维护医院、院区、科室与受检设备。
  • 检测仪器台账：查看与维护检测仪器资料（证书、有效期等）；异常占用时可手动 落库。详见专篇 检测仪器台账。
  • 用户管理：创建并管理您本人建立的检测流程岗位账号。
  • 委托业务使用说明：即本站，随时可查阅。

二、推荐业务顺序（委托统筹）

  1. 维护委托单位与设备
    进入 医院信息管理，新建或选择医院 → 院区 → 科室，登记受检设备（名称、型号、额定参数等）。后续立项与报告会引用这些信息。
  2. 创建团队账号
    进入 用户管理，为检测员、校核员、编制人、审核人、授权签字人等检测流程岗位分别建账号。您只能分配这五类岗位，且只能编辑/删除本人创建的账号。
  3. 立项与挂任务
    在 项目工作台 点击 新建委托（或从 委托管理 跳转），选中项目后勾选本项目要做的标准检测任务并 保存。无需进入任务模板库——系统已开放全部任务模板供您选用。
  4. 人员分工与 App 派工
    在 项目工作台 → 人员派工 指定统筹人、登记检测员等各岗位参与人；登记后任务自动同步到 App。详见 分工与报告导出 第二节。
  5. 跟踪进度
    日常在 委托管理 查看各委托完成度与提醒；需要改设备、改人员时回到 项目工作台。
  6. 导出现场记录、报告与合并交付
    App 提交后，在 文件库管理 依次：手动导出 PDF（现场记录）→ 导出合并报告 / 手动导出报告（单台报告）→ 报告合并（多份报告合订）。逐步说明见 分工与报告导出。

三、与检测流程岗位的分工

您创建的账号主要在 App 完成现场检测与签字；部分岗位会在 Web 文件库管理 上传或查看资料。派工前建议阅读本站 检测流程岗位 一篇，与团队对齐「谁填、谁校、谁编审、谁签发」。

小结：委托统筹回答的是——「从维护委托方资料、建团队、立项派工，到在文件库完成导出与合并交付」在后台分别点哪里、按什么顺序做。
