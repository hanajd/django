文件库

入口：左侧 文件库管理。打开后请关注顶部分类标签（下以 紫底 标出常见名称）：同一文件放进正确分类，后续填报、导出、合并才能被系统正确引用。

一、模板

  • 放什么：空白或半空白 PDF、坐标类 JSON、前端规则 JSON、与版式相关的配置导出等。
  • 什么时候用：新建或改版检测原始记录 / 报告版式时；需要试填、试导出 PDF 时。
  • 与模板编辑器的关系：先点击顶部 模板 分类，在列表中找到目标 PDF，再点击该行上的 编辑模板 进入 模板编辑器（需具备模板编辑器权限）。在编辑器中保存的 JSON 一般也会回到本分类。
  • 操作建议：上传、删除、下载等操作通常对应行内的 上传、下载 等按钮；若呈灰色，请读页顶提示。

二、现场记录

  • 放什么：现场工作已形成、需要归档的现场记录类 PDF 或相关结果（以单位定义为准）。
  • 什么时候用：点选顶部 现场记录 分类后，再使用列表上方的上传、生成或导出类按钮（名称以界面为准）。在模板编辑器中也可将 导出已填写 PDF 时的保存目标选为本分类。

三、报告

  • 放什么：对外出具的正式报告 PDF 等。
  • 什么时候用：切换到 报告 分类后管理成品；从模板编辑器导出时也可在保存目标下拉中选「报告」类选项。
  • 多份合并：在报告列表中按页面说明勾选多份文件后，点击 合并 或类似名称按钮；若按钮不可用，请阅读页顶灰色说明。

四、附件与其他分类

  • 点击 附件（若单位启用该分类）存放说明性文档、补充照片等，避免与正式记录、报告混淆。
  • 原始材料 / 识别结果等：若顶栏存在对应标签，按单位制度归档即可。

五、通用操作提示

  • 上传前确认当前项目是否已在 项目工作台 中选中（若本页与项目绑定）。
  • 下载、删除等若呈灰色：多为无写权限或流程锁定，以页面提示为准。

小结：文件库回答的是——「资料按性质放在哪一类、哪一步该上传、后面哪个功能会引用」。
