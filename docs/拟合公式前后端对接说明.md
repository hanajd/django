# 拟合公式 + R²：前端对接说明

后台只下发配置；**系数与 R² 均在前端算**。条件公式约定见 [`条件公式与前端type约定.md`](./条件公式与前端type约定.md)。

---

## 1. 两个栏位

| | 拟合公式（主格） | R²（从格） |
| --- | --- | --- |
| 识别 | `type: computed` + `displayFormat: "latex"` + `fitBinding` | `type: computed` + 普通算术式（含 `ln`） |
| `expression` | `fit(y=...)` 待定系数模型 | 已展开的 Pearson 式，**直接求值** |
| 展示 | MathJax 渲染方程 | 数值；可挂 `judgmentCriteriaByTestType` |

主格 `fitBinding.r2FieldId` 指向 R² 栏；R² 可镜像同组 `x`/`y`，其 `r2FieldId` 为空。

---

## 2. 下发 JSON（胃肠机实样精简）

**主格**

```json
{
  "id": "f1242",
  "type": "computed",
  "displayFormat": "latex",
  "fitBinding": {
    "x": ["f179", "f180", "f181", "f182", "f183"],
    "y": ["f195", "f196", "f197", "f198", "f199"],
    "r2FieldId": "f200"
  },
  "formulaRules": [
    { "label": "线性", "condition": "f1238", "expression": "fit(y=a*x+b)" },
    { "label": "对数", "condition": "f1071", "expression": "fit(y=a*ln(x)+b)" },
    { "label": "指数", "condition": "f1072", "expression": "fit(y=a*exp(b*x))" }
  ],
  "formula": "if(f1238,fit(y=a*x+b),if(f1071,fit(y=a*ln(x)+b),if(f1072,fit(y=a*exp(b*x)),\"\")))"
}
```

**R²**（`expression` 为完整展开式，此处省略中间项）

```json
{
  "id": "f200",
  "type": "computed",
  "fitBinding": {
    "x": ["f179", "f180", "f181", "f182", "f183"],
    "y": ["f195", "f196", "f197", "f198", "f199"],
    "r2FieldId": ""
  },
  "formulaRules": [
    { "label": "线性", "condition": "f1238", "expression": "((((5)*((f179)*(f195)+...))))" },
    { "label": "对数", "condition": "f1071", "expression": "((((5)*((ln(f179))*(f195)+...))))" },
    { "label": "指数", "condition": "f1072", "expression": "((((5)*((f179)*(ln(f195))+...))))" }
  ],
  "judgmentCriteriaByTestType": { "acceptance": ">=0.98", "status": ">=0.95" }
}
```

点列：`fitBinding.x[i]` 与 `y[i]` 一对。未写 `precision` 时按 **2**。

---

## 3. 前端怎么算

与其它 `computed` 相同：按 `formulaRules` 取**首个 `condition` 为真**的规则（全空则下选 / 单条直接用）。

| 命中 `expression` | 做法 |
| --- | --- |
| `fit(y=a*x+b)` | 读有效点 ≥2 → OLS → 写方程 |
| `fit(y=a*ln(x)+b)` | 要求 x>0；对 `(ln x, y)` OLS |
| `fit(y=a*exp(b*x))` | 要求 y>0；对 `(x, ln y)` OLS，再 `a = exp(ln a)` |
| 其它（R²） | 当普通公式求值（需支持 `ln`、`if`） |

**主格未勾选、或有效点不足 / 不满足符号约束 → 清空结果，勿写假方程。**  
R² 无公式下拉；与主格同条件重算即可。

依赖变化即重算：`x`/`y` 各栏、各 `condition` 勾选框。

---

## 4. 方程展示（代入 a、b 后）

| 模型 | `equationLatex` |
| --- | --- |
| `fit(y=a*x+b)` | `y = {a}x + {b}`（b&lt;0 用减号） |
| `fit(y=a*ln(x)+b)` | `y = {a}\ln x + {b}` |
| `fit(y=a*exp(b*x))` | `y = {a}{\rm e}^{{b}x}`（e 必须正体） |

系数建议按栏位 `precision`（默认 2）舍入。

---

## 5. 提交

```json
{
  "f1242": "y = 1.23x + 0.45",
  "f200": 0.99
}
```

主格至少交方程字符串（可用 `equationLatex` / `$$…$$`）；R² 交数值。

现场记录 PDF 导出时：`displayFormat: "latex"` 或整段 `$$…$$` 会经 **MathJax** 渲染成公式图，再按栏位坐标叠印（失败时回退 matplotlib mathtext）。

---

## 6. 注意

- 不要把 `fit(...)` 当 `avg(...)` 算术解析。
- 无 `fitKind` / `fit_eq()`；只认 `fit(y=...)`。
- 算术引擎需支持：`if`、`ln`、四则与括号。
