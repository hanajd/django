# 评价报告表（F.1）功能说明

> **易混**：侧栏「评价报告表」≠「评价报告书」。  
> - **本页 = F.1 评价报告表**（`perm_f1_eval`，`/files/f1-eval/`）  
> - 评价报告书 = LaTeX PDF（`perm_evaluation_report`），见 [评价报告书-LaTeX功能说明.md](评价报告书-LaTeX功能说明.md)  
> **整理日期**：2026-08-20

---

## 1. 定位

F.1 是预评价/控制效果类 **表单报告工作台**：在浏览器中维护项目、章节、表格、图件与附件相册，并调用生成库产出 PDF。主站以**文件工作区**为主（`media/f1_eval/`），不依赖一套完整业务 ORM（与检测 `InspectionSubmission` 不同）。

| 项 | 路径 / 包 |
|----|-----------|
| Web 入口 | `/files/f1-eval/`（`apps/core/urls.py`） |
| 视图 | `apps/core/f1_eval_views.py` 等 `f1_eval_*.py` |
| 权限 | `Role.perm_f1_eval`；门禁见 `library_access` |
| 工作区 | `F1_EVAL_WORKSPACE_ROOT` → 默认 `media/f1_eval/workspaces` |
| 生成库 | `F1_EVAL_PACKAGE_DIR` → 仓库根 `f1_eval_report/` |
| 独立工程 | `f1_eval_standalone/`（回嵌见其 `EMBED_INTO_DJANGO.md`） |

---

## 2. 用户能力

| 能力 | 对应 API 前缀（节选） |
|------|------------------------|
| 项目列表 / 新建 / 打开 / 删除 / 派工 / 绑定医院 | `/files/f1-eval/api/projects*`、`hospitals`、`assignable-users` |
| 章节读写 | `api/section`、`api/save-section` |
| 表格 CRUD / 行列操作 / Excel 导入导出 | `api/table*`、`import-excel`、`export-excel` |
| 图件上传与图注 | `api/upload-figure`、`save-figure-caption`、`delete-figure` |
| 附件相册 | `api/upload-attachments`、`attachment-album`、`update/delete-attachment` |
| 封面元数据与证书图 | `api/cover-meta`、`upload-cover-certificate`、`upload-info-sheet` |
| 格式字段 / 模板预设 / 预览 | `api/save-format*`、`format-templates`、`preview-format` |
| 公共模板 | `api/common-templates`、`media/common-template` |
| 生成 PDF | `api/generate` |
| 媒体与下载 | `media/attachments|assets/...`、`download/<kind>/` |

完整路由在 `apps/core/urls.py` 中搜索 `f1-eval`。

---

## 3. 与评价报告书的分工

| | 评价报告表 F.1 | 评价报告书 |
|--|----------------|------------|
| 产物形态 | 表单式 PDF（`f1_eval_report` 排版） | 完整报告书（LaTeX 章节工程） |
| 编辑方式 | 工作台字段 / 表格 / 相册 | 结构化块编辑 + 关键词 + 附录附件 |
| 数据落盘 | `media/f1_eval/` | `media/evaluation_reports/work/` |
| 权限 | `perm_f1_eval` | `perm_evaluation_report` |

评价部可同时拥有两套能力；产品上「表」偏填报，「书」偏正式文本报告。

---

## 4. 排障

| 现象 | 排查 |
|------|------|
| 侧栏无入口 | 角色是否勾选「评价报告表」；菜单是否绑定角色 |
| 生成 PDF 失败 | `f1_eval_report` 可否 import；`fonts/`；工作区写权限 |
| 与报告书搞混 | URL：`/files/f1-eval/` vs `/evaluation-reports/` |
