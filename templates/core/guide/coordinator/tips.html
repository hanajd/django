常见情况与排查

下列问题多由前置步骤或权限范围引起。灰底为菜单名，紫底为页内按钮或分类。

{% if guide_coordinator_is_coordinator %}

一、委托统筹专用

  • 找不到任务模板库 / 模板编辑器：属正常，委托统筹使用系统预置的全部标准任务，在 项目工作台 直接勾选任务即可。
  • 用户管理列表为空：仅显示您本人创建的流程岗位账号；需点 新建用户。
  • 无法编辑某用户：该账号非您创建，或岗位不在五类流程岗位内。
  • 医院信息无法保存：检查必填项；新建医院/科室无需「编辑模式」，直接在浏览页操作。
  • App 无待办：检查 人员派工 是否已登记该人（见「分工与报告导出」）。
  • 混淆两种「合并」：导出合并报告（现场→一份报告）与 报告合并（多份报告 PDF 合订）不同，见专篇第五节。
  • 仪器仍显示已出库、新项目派不出库：到 检测仪器台账 筛选「仅已出库」，确认前序项目是否已结束；若仪器已实际归还，点 落库 恢复在库（见「检测仪器台账」专篇）。
  • 报告合并目录不对：输入须为各设备单台原始报告；检查医院信息中设备名称型号；合并后目检目录。
  • 导出按钮灰色：App 未提交、未勾选文件、分类不对，或无导出权限。
{% else %}

一、流程岗位专用

  • App 没有待办项目：联系委托统筹确认是否已在 人员派工 登记并同步任务，是否用本人账号登录。
  • 看不到项目工作台：须已被统筹在 人员派工 登记并同步任务；左侧应出现 项目工作台，列表仅含分配给您的项目。
  • 文件库为空：确认 App 是否已提交；确认顶部项目筛选与分类标签。
  • 无法删除文件：只能删本人上传的；系统生成文件需联系委托统筹处理。
  • 无法导出报告 / 合并报告：检测员、校核员仅可在文件库 检测提交 使用 手动导出 PDF（现场记录）；导出报告与报告合并需编制人及以上岗位。
  • 项目工作台只能查看不能改：检测员、校核员可打开已分配项目查看进度，委托立项 / 派工 / 仪器管理为只读；编制人、审核人、授权签字人可编辑。
{% endif %}

二、列表是空的

  • 在 项目工作台 确认已选中项目（若页面与项目绑定）。
  • 确认检测任务已勾选并 保存。
  • 文件库检查是否点对了顶部分类标签。

三、按钮灰色或无权

  • 阅读页顶灰色说明：常见为未勾选文件、份数不足、流程未走完。
  • 流程岗位删除他人文件会被拒绝，属权限设计。

四、左侧没有某个菜单

  • 菜单由角色决定：委托统筹与五类流程岗位可见项不同，并非漏配。
  • 需要模板维护、角色管理等能力时，联系单位系统管理员，非委托统筹权限范围。

五、与单位制度不一致时

若贵单位另有书面制度或培训材料，以单位规定为准；本说明描述委托业务账号的常见默认用法。

仍无法解决时，流程岗位请联系委托统筹；委托统筹可联系单位系统管理员。
