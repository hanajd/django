\section{不同运行状态下的辐射源项}

\subsection{正常运行状态下的辐射源项}

\subsubsection{医用电子直线加速器正常运行状态下的辐射源项}

正常出束时产生 X 射线和/或电子线；高能 X 射线（一般 $>10\,\mathrm{MV}$）时尚需考虑中子及感生放射性等。泄漏辐射、散射辐射随照射条件变化。

\subsubsection{CT模拟定位机正常运行状态下的辐射源项}

正常扫描时产生 X 射线（管电压、管电流相关）。

\subsection{异常运行或事故状态下的辐射源项}

\subsubsection{医用电子直线加速器异常运行或事故状态下的辐射源项}

\begin{enumerate}
\item 照射剂量偏离处方剂量等异常照射；
\item 未按程序操作造成的人员误照射；
\item 人员误入或滞留机房造成的误照射；
\item 机房屏蔽设施损坏造成机房外额外照射。
\end{enumerate}

\subsubsection{CT模拟定位机异常运行或事故状态下的辐射源项}

\begin{enumerate}
\item 设备故障引起人员误照射；
\item 未按程序操作造成的人员误照射；
\item 人员误入或滞留机房造成的误照射；
\item 机房屏蔽损坏造成机房外额外照射；
\item 患者未正确使用个人防护用品导致额外照射。
\end{enumerate}

\section{放射性职业病危害因素的识别和分析}
