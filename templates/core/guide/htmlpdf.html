模板编辑器

用途：在浏览器中打开模板 PDF，用鼠标标出文字填写区、勾选框、图片区，保存为坐标 JSON 与（可选）前端规则 JSON，并可把试填结果导出为已填写 PDF写入文件库。下文 紫底 均对应工具栏或页面上可见的按钮/下拉文字，请到编辑器里对照查找。

入口：文件库管理 → 顶部点 模板 → 在目标 PDF 行点击 编辑模板（需具备「模板编辑器」或文档识别等相关权限）。打开后：上方为工具栏，左侧为填写区列表，中间为 PDF 画布。

一、推荐操作顺序（首次建议严格按序）

  1. 等待 PDF 加载完成：进入后若画布空白，请稍候；若长时间失败，检查网络或重新从文件库点击 编辑模板。
  2. 在工具栏先用下拉框 选择模板 JSON 选中一条已保存的 JSON（若有）。
  3. 点击 从文件库载入版式，把 JSON 里的框线、类型套到当前 PDF。
  4. 若无 JSON，点击 按红字自动框选（仅当待填项为 PDF 中文本层的红色字时有效）；生成后在左侧列表核对位置。
  5. 补画空白：依次点 框选文字填写区、添加勾选框、添加图片区域，再在画布上拖拽（按钮高亮即处于画框模式）。
  6. 在左侧「填写区列表」改每个框的名称，与单位 JSON 的 id 约定一致；f1、f2… 为 PDF 顺序号。
  7. 核对底图时可点 隐藏填写框，再点一次变为 显示填写框。
  8. 点击 保存坐标模板 JSON 写入文件库模板分类；若需网页填报，再点 保存前端规则 JSON。
  9. 试填后，在工具栏右侧下拉选择 保存到现场记录 或 保存到报告，再点 导出已填写 PDF。

二、工具栏按钮说明（与界面对照）

选择模板 JSON（下拉框）
仅切换候选文件，不会自动套版；需再点 从文件库载入版式 或 载入已保存的填写内容。
从文件库载入版式
前提：下拉框已选 JSON。作用：加载框线、类型等。典型场景：换 PDF 修订版但版式与旧 JSON 一致。
载入已保存的填写内容
在不改变框线的前提下回填已保存的填写值；适合换底图对比试填。
文件名输入框（占位如「保存到文件库时的文件名」）
保存 JSON / 导出 PDF 时作为建议文件名，可留空使用系统默认。
保存坐标模板 JSON
写入文件库 模板 分类，供下次载入或程序填数。
保存前端规则 JSON
生成前端可渲染的规则结构；与仅坐标 JSON 用途不同。
隐藏填写框 / 显示填写框
切换画布上框线可见性，不删数据。
框选文字填写区
拖拽生成文本框；画完后在左侧列表改标签与业务 id。
按红字自动框选
识别红色文本层批量建框；黑字、扫描图请改用手动 框选文字填写区。
添加勾选框
拖出小矩形作打勾位。
添加图片区域
拖出区域用于粘贴或上传图片。
保存到现场记录 / 保存到报告 + 导出已填写 PDF
下拉决定写入文件库的分类；导出已填写 PDF 把当前填写压入 PDF 并保存。

内测项：保存前端规则 JSON、定位前缀、向右填、向左填 仅对系统管理员显示；其它账号以界面为准。

三、左侧「填写区列表」

  • 序号与画布角标一致；悬停列表行与画布框可联动高亮。
  • 点击行内空白可滚动定位到对应框；在行内编辑名称会同步画布。
  • 使用 按红字自动框选 后，红字填写区在画布上常以红字显示，便于与底图区分。

四、填写区命名（中文 + 下划线）

填写区名称建议以中文为主，用下划线串联行主题与列名，例如 检测日期_年、额定参数_kV。系统自动生成的顺序号（如 f1、f2）与阅读顺序对应；人工阅读与表格对应关系以中文名称为准。
