## 2. 分现象说明

### 2.1 报出值变成范围值

- 全部目标模板：**测量点** `report_d` / `report_d_2` **没有**写成 `min(...)~max(...)`。
- **本底报出格**（如胃肠 `f1010`、C形臂 `f494`）统一为：

  `校准因子 * min(①…⑩) ~ 校准因子 * max(①…⑩)`

  这是本底「水平及范围」的正确形态，不是测量报出。

- 口腔 CBCT 部分报出公式会 **引用本底读数做本底扣除**（`avg(f886…)` 等），结果仍是单值表达式，不是范围输出；但若本底未填，观感会像「报出算不动」。

### 2.2 均值不计算（主因）

**双组设备（胃肠 / 动态DR / 口腔CBCT / 口内牙片）** 共性：

```text
同一行绑定示例：
  reading_1/2/3、mean_m、report_d     ← 第一组正常
  mean_m_2、report_d_2 有 pdfFieldId
  reading_1_2 / reading_2_2 / reading_3_2 全空   ← 第二组均值无法 avg
```

| 设备 | 典型「第二组无读数」行数 |
|------|-------------------------|
| 胃肠机、动态DR | ≈19 / 模板 |
| 口腔CBCT | ≈18–20 / 模板 |
| 口内牙片机 | ≈8 / 模板 |

**单组设备（C形臂、乳腺DR）**：仅 1 格均值不是 `avg`（多为单读数镜像如 `f475`→`f476`，边角行），不是整表失效。

### 2.3 报出值不计算

| 严重程度 | 模板 | 问题 |
|----------|------|------|
| 高 | C形臂验收/状态 | **无有效 `reportValueRules`**；验收另有 2 个报出格空公式 |
| 高 | 乳腺DR 状态部分变体（`08d9…` / `3ca4…` / `aad3…`） | RVR=0，约 **22/63** 报出格空公式（勿用这些变体；`668dae…` 正常） |
| 高 | 胃肠/动态DR「坏」变体（`7ae3…` / `dfbb…` / `acb9…`） | RVR 6 条但 **expression 全空**，另有约 7 个报出格空 |
| 中 | 双组均值缺读数 | 第二组 `report` 公式依赖 `{mean2}` 时，均值空 → 报出也空 |

### 2.4 本底水平 ③⑤⑧⑩ 自动计算

对 `infer_background_geometry_from_fields().readings` 按序 ①–⑩ 检查：

- **当前全部目标 current：读数格无 `avg` / 无 fieldExpression**。
- **未**再出现「本底 pid 被绑成 `mean_m`」的混绑。
- 本底报出格保留范围公式（预期）。

与 2026-07-17 全量审计对比：当时这批设备几乎都有「绑定混入本底 + 本底误写 avg」（③⑤⑧⑩ 正是易被写成均值的列位）。**坐标模板侧已修掉**；若现场仍自动算，优先核对 App 是否仍用旧导出 JSON。

## 4. 根因归纳（便于修）

1. **双组列绑定不完整**：版式判成 `per_row_avg_dual`，但不少行只认出第二组均值/报出列，未认出第二组三次读数 → 均值/报出链路在第二组断裂（对应「均值不计算」「报出不计算」）。
2. **C形臂章节报出规则缺失**：靠格上散落公式，无统一 `reportValueRules` → 易漏格。
3. **同目录多 JSON 变体质量不一致**：坏变体 RVR 被清空后仍留在 `current/`，若任务指到坏文件会复现「报出不计算」。
4. **本底③⑤⑧⑩**：属历史 avg 误写类问题，**当前模板已净**；本底报出范围公式保留。

---

## 5. 建议修复顺序

1. 修双组 `fieldBindings`：为虚悬的 `mean_m_2`/`report_d_2` 补齐 `reading_*_2`，或删掉误认的第二组槽位。  
2. 给 C形臂补 `reportValueRules`（及空报出格）。  
3. `current/` 只保留合格变体，坏 JSON 归档。  
4. 若现场仍见本底③⑤⑧⑩自算：对比该任务实际下发的前端 JSON 与本审计坐标模板是否一致。
