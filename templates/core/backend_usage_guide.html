第一次使用本后台时，建议按下面顺序浏览一遍：先熟悉项目工作台，再使用文件库和任务模板库。每一节只说明「在什么环节、要做什么、为什么要做」，便于您把线上操作和实际业务对上号。

跳转到： 整体顺序 项目工作台 文件库 任务模板库 记录与报告 常见情况

一、整体工作顺序（心里先有这张图）

实际业务里，一般是：确定做哪个项目 → 明确要做哪些检测项 → 准备模板和资料 → 现场或线上填报 → 形成现场记录 → 再形成报告。后台里的菜单就是按这条线拆成几块，您不必一次全弄懂，按项目推进即可。

  1. 在项目工作台里选中您的项目，确认「要做哪些检测」已经挂到项目上。
  2. 在文件库里按需要上传模板、附件、现场或报告相关文件（具体分类见下一节）。
  3. 在任务模板库里维护「每种检测长什么样」的模板（尤其是带固定版式的 PDF），需要时再试生成一份看效果。
  4. 检测数据齐全后，在文件库或项目相关页面里，按界面提示生成或合并现场记录、报告。

二、项目工作台：每一步要达成什么

入口在左侧「项目工作台」。这里是围绕一个具体项目做事的中心页面。

  • 先选项目：左侧列表里点您的项目。后面所有「挂任务、看流程、分任务」都是在当前选中的项目下进行的。
  • 把检测任务挂到项目上：意思是告诉系统「这个项目要做哪些标准检测」。挂好之后，后面文件、分配、出记录才会和这个项目对上号。勾选后记得按页面上的保存或确认。
  • 看流程里每个岗位是谁：编制、审核、签字等环节分别由谁负责，在这里能一目了然。若您是新手，可以先确认自己的名字是否出现在该出现的环节上。
  • 给外业或手机端准备任务：在「分配」一类标签里，按页面说明把任务分给对应人员；他们登录自己的账号后，才能在自己的项目里看到该做的检测。
  • 若页面里有前往任务模板库的链接，一般是让您去配好「版式、空白表、默认仪器」等，配完再回到项目里继续。

小结：项目工作台回答的是——「这是哪个项目、做哪些检测、谁在什么环节负责」。

三、文件库：每个区域什么时候用

入口在左侧「文件库管理」。顶部分类可以理解成不同性质的资料柜，按业务阶段去对的柜子找或放文件即可。

  • 和版式、空白表单有关的：通常放在「模板」一类。以后填数、出 PDF 往往会用到这里的文件。
  • 检测原始材料、识别结果：有的单位会把扫描件、自动识别结果放在对应分类里，按您单位的习惯和页面上文字说明操作即可。
  • 现场工作形成的结果：一般在「现场记录」相关区域查看或上传，表示「现场这一趟留下了什么」。
  • 正式报告：在「报告」相关区域管理；需要合成一份总报告时，按文件库里的勾选说明操作。
  • 附件、照片、说明性文档：用「附件」一类，避免和正式记录、报告混在一起。

小结：文件库回答的是——「资料放在哪、什么时候该上传、后面哪个环节会用到」。

四、任务模板库：什么时候来这里、做完要做什么

入口在左侧「任务模板库」（若当前账号左侧没有这一项，说明您的工作范围不包含维护模板，可请单位管理员协助）。

  • 什么时候需要新建：单位新增一种检测类型、或需要一套新的空白版式时，在这里点「新建」，填名称并选择这份模板将来是出「现场记录类」还是「报告类」的 PDF。
  • 新建之后必做的一步：回到项目工作台，在任务列表里把刚建好的这一项勾选进具体项目。否则系统只知道「世界上有这样一个模板」，还不知道哪个项目要用它。
  • 「模板与仪器」一类页面在干什么：把文件库里已经上传好的版式文件，和这份任务绑在一起；有需要时还可设默认设备清单，减少现场重复选择。
  • 「试导出」在干什么：选一个已有检测数据的项目，试着生成一份 PDF，用来检查版式、字段是否填对。若提示缺少数据，说明该项目里还没有对应的检测填报，需要先在业务流程里完成前面的步骤。

小结：任务模板库回答的是——「每种检测长什么样、用什么版式、和哪些文件绑在一起」。

五、现场记录和报告：在流程里处于什么位置

  • 现场记录：对应「现场已经做完、要把结果固定下来」这一步。通常在检测数据或现场表单齐备之后生成或导出。
  • 报告：对应「对外出具正式结论」这一步。一般在现场记录和检测数据都齐了之后编制或导出。
  • 多份合成一份：若业务需要把多份报告合成装订，在文件库报告区域按页面上的文字说明选择多份文件再执行合并即可；若按钮不可用，按页面提示检查是否选对项目或选对文件类型。

六、常见情况（从「业务上缺哪一步」想）

  • 列表是空的：先确认左侧是否选中了项目；很多列表只显示「当前项目」下的内容。再确认前面是否已挂任务、是否已有人填报。
  • 按钮是灰色的或点不了：阅读按钮旁或页面顶部的灰色说明文字，多半是前序步骤未做完（例如未选项目、未选文件、没有可合并的多份报告等）。
  • 导出 PDF 提示缺数据：表示在选定的项目里，还没有对应的检测填报或记录，需要先在项目工作台与业务流程里完成检测与登记。
  • 左侧没有某个菜单：不同岗位职责不同，看不到的菜单表示不在您的工作范围内，可向单位管理员确认应由谁操作。

若界面与单位制度有特殊约定，以单位培训或管理员口头说明为准；本说明仅描述常见后台操作顺序。
